### 2. MCP 两周年：Skills over MCP 公共 beta，Tasks 与 Elicitation GA，File Uploads 将至（Anthropic，11 月 24 日）

- **发生了什么**：MCP（Model Context Protocol）发布两周年，Anthropic 11 月 24 日一次补齐四件套——Skills over MCP（公共 beta）、Tasks 与 Elicitation（正式 GA）、File Uploads（即将推出）。官方博客原话：Claude 与服务器的合作方式"越来越像与另一个 agent 合作：向它学习、向它委派、与它交换输入和文件"。
- **四件套各管什么**：
  - **Skills over MCP**：服务器不只给工具，还能附带"怎么做"的技能（流程、业务规则、领域经验）；Claude 只在需要时加载，用完即走，服务器更新技能自动同步。首批合作方：Shopify（设计与更新商户店铺）、HubSpot（客户 onboarding）、Atlassian（组织上下文分析）、Carta（即将上线，从上传文件起草与发行股权）。
  - **Tasks**：服务器可以在后台跑耗时操作甚至完整 agent 循环，Claude 不用干等、稍后取结果——长活不再卡住对话。
  - **Elicitation**：服务器中途停下来向用户要输入或确认（表单或链接），比如 Supabase 确认创建付费项目与破坏性 SQL、Railway 确认删除服务、GitHub 删库前要求输入仓库名——高风险动作先过人。
  - **File Uploads（将至）**：PDF、表格、图片直接传给 MCP 服务器，不再经过上下文窗口。
- **规模数字（Anthropic 厂商口径）**：MCP SDK 月下载 7 亿+ 次；Claude 上已有 10,000+ 连接器。
- **谁能用**：Skills over MCP 在 Pro、Max、Ultra 默认开，Team 需管理员开，Enterprise 随后；Tasks 与 Elicitation 在 Pro、Max、Ultra 已 GA，正向 Team、Enterprise 铺开；四件套都在 Claude 与 Claude Code 里，且属于开放 MCP 规范的扩展——支持的服务器在其他兼容客户端里也能用。Claude Code 需 v2.1.331+（Skills over MCP）/ v2.1.304+（Tasks）。
- **与你的关联**：这是你最该看的一条。MCP 从"连上"（2024 年 11 月 25 日发布）走到"管住、教方法、跑长活"——与 10 月 6 日 Snyk MCP Governance、10 月 7 日 NVIDIA OpenShell、10 月 6–7 日 Atlassian AMP 是同一条"agent 从连上走向管住"的主线，今天补上的是"服务器反过来教 agent 做事"这一块。你 Codex 团队里的技能（SKILL.md）以后可以直接由 MCP 服务器下发、自动更新，不用再手动装一份；Elicitation 则是"高风险动作先过人"的现成机制，值得抄进你团队的流程里。

### 3. Claude "Install as app"：artifact 一句话变 Mac / Windows 桌面 App，免费计划也能用（Anthropic，11 月 24 日 beta）

- **发生了什么**：Anthropic 11 月 24 日推出 "Install as app" beta：Claude 里做出来的 artifact（计时器、追踪器、改名工具这类小工具），点分享菜单里的 "Install as app" 就能装成独立桌面 App——有自己的图标、独立窗口，像正常程序一样打开；artifact 一改，装好的 App 自动跟着更新。不用打包、不用签名、不用 API key、不用另外登录，走你已有的 Claude 账号。
- **三档权限，关键在第三档**：
  - **默认**：只能做浏览器里能做的事；
  - **应用权限**：可发桌面通知、加 Mac 菜单栏 / Windows 系统托盘、窗口置顶、全局快捷键；
  - **完全访问（Full access）**：可运行程序、读/改/删本地文件，每次操作不再逐项问你。
- **安全红线（官方原话口径）**：Anthropic **不预审**这些 App；完全访问只能给**你自己做的** App（Team/Enterprise 计划内可给同组织同事做的），别人分享给你的 App 开不了完全访问。每次 App 更新后权限要重新确认；丢了共享 App 的访问权，约 20 分钟内它的程序会停。
- **范围与限制**：beta 覆盖全部计划（含 Free），Team 默认开、Enterprise 需管理员开；需 Claude for Mac/Windows 6.28899.0+；Linux、网页、手机暂不支持；Docs/Slides/Sheets 这类模板 artifact 不能装；HIPAA 配置的组织没有这个功能；做 App 与 App 每次调 Claude 都计入计划用量；打开 App 须联网并登录 Claude。
- **官方自带例子**：Anthropic 员工已用它做了图层修图 App Linnet、文件管理器 Phosphor、自动整理文件夹的 Sift、带 Claude 帮忙的终端 Tern、监控电脑状态的 Vitals。
- **与你的关联**：你 Codex 设计角色平时一句话出小工具、做品牌视觉稿，这个功能等于"出图/出工具 → 直接变桌面 App"，不用再教打包。先拿你自己的小工具试（比如一个煲王菜品图批量改名器），别给来路不明的 artifact 开完全访问——这是今天日报里最值得上手试的一条，也是"AI 助手从聊天框长出来"的最新一步（与 Claude 进 Google Workspace 同一条线）。
- 出处：Anthropic 官方文章《Turn artifacts into Mac and Windows apps》（claude.com）；https://www.neowin.net/news/anthropic-now-allows-users-to-convert-their-claude-artifacts-as-mac-and-windows-apps/ · https://www.macrumors.com/2026/11/25/claude-install-artifacts-desktop-apps/ · https://www.notebookcheck.net/Claude-artifacts-become-desktop-apps-What-full-access-lets-them-do.1459673.0.html

### 4. GPT-6.2 设计蛋白：322 个里 35 个在湿实验里真结合了，命中率 10.9%（OpenAI 研究，11 月 24 日）

- **发生了什么**：OpenAI 11 月 24 日发研究文章《GPT-6 models demonstrate intrinsic protein-design capabilities》及预印本：GPT-6 家族只用推理与通用代码（不靠专用生物模型做设计）设计新蛋白结构与氨基酸序列；合作方 Onava 把设计做出来、在实验室里测——322 个 minibinder（小结合蛋白）里 35 个结合上了目标，命中率 10.9%，5 个靶点全有命中：IL-17A 18 个、VEGF-A 8 个、PD-L1 5 个、IL-7Rα 3 个、TrkA 1 个。
- **先看细则再看标题**：序列不是 GPT-6.2 自己写的——SolubleMPNN 负责配氨基酸序列，Boltz-2、OpenDDE、ESMFold2 负责筛候选；OpenAI 自己写明"结果尚未证明模型能端到端、零样本从头设计 minibinder"。结构预测仍是短板：同一任务上 GPT-6.2 的 TM-score 为 0.38，ESMFold2 为 0.93。14 项蛋白任务里，最新内部模型在多数任务上"与专用模型相当或更好"，但完整结构预测明确是弱项——OpenAI 自己的词是"参差不齐的能力边界"（jagged capability frontier）。
- **口径**：厂商研究口径，预印本**未经同行评审**；结合不等于有功能，文章未公布亲和力常数、效力或毒性数据；OpenAI 同时提示该能力"也可能被滥用"，指向其 Preparedness Framework 的生物安全部分。
- **与你的关联**：通用大模型第一次拿出湿实验数字，跨进专用模型的地盘——"一个通用模型顶多个专用模型"是 GPT-6 家族的卖点，也是判断各家模型路线的标尺。但 10.9% 这个数字本身比标题小得多，且离不开专用工具链，别当成"GPT-6 会做药了"。

### 1. kaankiziltug/logo-design-skill——按真设计师流程做 logo 的技能：先问 brief、查 1,400+ 真实 logo 库、3 个 SVG 概念过 16px 测试才给你看（2026-09-26 建仓，今日核实 7,717 star）

### 5. Co-Design Bench：编码智能体真实任务"全做完"只有 26.4%——旧基准 99%+ 已饱和（11 月 9 日报道，论文口径）
- **含义**：阿里巴巴与亚洲多所大学研究者发布的新基准 Co-Design Bench，取材 26,314 场真实编码会话里的 37,463 条查询，测 agent 从头到尾完成真实任务的能力。结果：最好的编码 agent 也只能完整做完 26.4% 的任务；GPT-6 Astra 平均满足每项任务 69.9% 的需求，但多数任务总会留下一两处细节没做完。
- **关键发现**：同一批模型在旧基准上能拿 99%+，作者认为旧基准已饱和、会系统性高估端到端可靠性；任务同时涉及布局、设计、交互与内容改动时成绩掉得最厉害；跑 agent 的环境（harness）本身影响成绩——Qwen3.8-27B 在大改任务上换个环境能从 75% 掉到 56%；多给 token 也没用。
- **与你的关联**：这是你搭 Codex 团队最该贴在墙上的一条——"模型在榜单上 99 分"不等于"交给它一个真实任务能一次做完"。验收标准别只看跑没跑通，要按需求逐条核对（Astra 平均还剩 30% 的需求没满足）；以及你团队里"大总管把关 + 资料官预整理"的流程，正好是对着这个 26.4% 的缺口长的。
- 出处：https://the-decoder.com（经 https://killtheai.com/news/top-10-ai-news-today-november-9-2026/ 转述）· 论文 arXiv: Co-Design Bench: Multimodal Collaborative Coding Evaluation for Agentic Models

### 6. Dots 会自己去邮箱取验证码登录了（11 月 7 日报道，跟进）——agent 自主登录的最后一道坎
- **含义**：OpenAI 的常驻 agent Dots 新增能力：用户连好邮箱并授权后，注册/登录流程发到邮箱的 6 位验证码，Dot 能自己去收件箱里找到、填进正在等的表单，完成 2FA 登录。Dots 9 月 29 日 DevDay 发布，跑在 GPT-6 Astra 上，通过插件接 4,000+ 应用。
- **边界（报道口径）**：早期用户反馈称，即便给了邮箱权限，Dots 在真正输入验证码前仍会犹豫——内置安全配置在起作用；交易确认、敏感数据修改等高风险动作同样受限。是否碰邮箱完全取决于用户授权。可用范围仍限 ChatGPT Pro 与 Business Premium 订阅用户（每份合规订阅含一个 Dot），Enterprise 为 beta。
- **同批小更新**：ChatGPT 新增 Faro 与 Tonada 两个阿根廷西班牙语语音，已全球上线（TestingCatalog 11 月 9 日上午披露）。
- **与你的关联**：验证码一直是 agent"替你跑完一件事"的最后人工卡点——这道坎一过，Dots 就能独立走完订票、购物、企业软件登录这类全流程；但代价是"人来证明你是你"的 2FA 变成 agent 的一个自动步骤，邮箱授权给 agent 之前，先想清楚这个邮箱还绑着什么。另：你 Codex 团队的通知官若走邮箱取码，同样要先定好授权边界。
- 出处：https://cryptobriefing.com/openai-dots-agents-2fa-email-codes/（2026-11-07）· https://www.fathom.news/openai-dots-email-login-codes/

## 六、今日好用开源技能

### ① Elephant-Goldfish Model（Google 开源，google/elephant-goldfish-model）：让 agent 写规格文档时"大象起草、金鱼挑刺"
- **一句话能力**：Google 开源的 agent 插件——按 Dave Rensin 的"大象-金鱼"模型做软件规格设计：Elephant（大象）攥着项目上下文起草规格文档，Goldfish（金鱼）评审员用全新的子智能体上下文、不带此前对话偏见去审稿，专挑没说出口的假设与盲点；人只负责拍板取舍、批准规格后再让 agent 动手写代码。
- **为什么今天推（11 月 8 日出圈，非今日首发——日期说清楚）**：仓库建于 2026-09-13，11 月 8 日多家媒体报道后热度起来；今日核实 15,952 stars、1,162 forks、Apache 2.0。推它的理由很贴你：你 Codex 团队的流程就是"资料官预整理 → 执行角色干活 → 大总管把关"，EGM 把"把关"这一步做成了可复用的技能——评审员每次都用新鲜上下文，避免"自己审自己"的盲区；而且它不是官方支持的 Google 产品（README 原话），用之前先看清这点。
- **安装 / 获取来源**：https://github.com/google/elephant-goldfish-model（Apache 2.0，今日在 GitHub 原页面核实）。Claude Code：`claude plugin marketplace add google/elephant-goldfish-model` 后 `claude plugin install egm@egm`；Codex CLI：`codex plugin marketplace add google/elephant-goldfish-model` 后 `codex plugin add egm@egm`；Antigravity CLI：`agy plugin install https://github.com/google/elephant-goldfish-model`；ChatGPT / Codex 桌面端有已发布的插件列表可直接装。装完开新会话再用。
- **适用工具**：Claude Code / Codex CLI / Codex 桌面端 / ChatGPT 桌面端 / Antigravity CLI 与 IDE；另有 Cursor、Gemini、Copilot、OpenCode 适配目录。
- **一句话上手**：先跑一遍 `/egm-brainstorm`（聊清需求与取舍、产出 `concepts_brief.md`）→ `/egm-draft`（逐节起草 `design_draft.md`、每节停下来等你反馈）→ `/egm-review design_draft.md`（五阶段新鲜评审）；命令在 Claude Code 与 Antigravity 里要加 `/egm:` 前缀。另有 `/egm-review-loop`（自定义评审组）、drift report（对照代码查文档是否过期）。
- **安全提醒（必读）**：技能本身只是 Markdown 指令 + 评审流程，不执行代码；但评审要开全新的子智能体上下文——若你的 agent 环境开不了子智能体，EGM 会直接停掉评审（README 原话），先确认环境支持再装；规格文档里别写真实密钥与生产配置。
- **许可与时效**：Apache 2.0；明确声明"不是官方支持的 Google 产品"；与技能库中已有的 google/skills 是不同仓库，不重复收录。

### 1. DeepSeek、MiniMax 率先拿到"全球通行证"：出口管制≠关门，是注册制
- **含义**：10 月 16 日中国提议对 23 项 AI 技术（大模型、agent、算力集群）实施出口管制后，央视关联账号"玉渊谭天"10 月 22 日晚发帖：DeepSeek 与 MiniMax 已完成注册程序，获准开源与海外授权——是新规后首批放行的两家。商务部当时即表示"绝大多数 AI 技术仍可自由出口"，开源技术出口走简化许可。
- **为什么走红**：一周前管制消息出来时，市场担心中国开源模型"出海受限"；首批放行等于官方定调"鼓励开放"。DeepSeek、MiniMax 的开源权重和 API——他当便宜 worker 用的 GLM / DeepSeek / Kimi / Qwen 这一档——继续全球可用。
- **市场反应**：MiniMax 昨日（10-22）首次跌破 165 港元发行价（收 160.70），今日（10-23）反弹 +16.7% 收 187.60，破发次日收复发行价。
- **关联**：10-16 那轮管制是"参数与算力量级设门槛"；这次放行说明门槛管的是最尖端部分，开源生态照常——对他"GitHub 找现成轮子"没有实质影响。
- 出处：https://www.reuters.com/business/media-telecom/chinas-deepseek-minimax-win-approval-ai-global-use-state-media-affiliated-entity-2026-10-23/（Reuters 10-23，转述"玉渊谭天"10-22 晚帖文）· https://www.scmp.com/tech/policy/article/3371880/deepseek-minimax-secure-open-source-licenses-days-after-new-china-export-rules-state-media（SCMP 10-23，细节一致）。口径：官方关联账号发帖 + 商务部表态，非两家公司直接公告。

### 3. Anthropic 把 Agent Skills 捐给 Linux Foundation：MCP 之后第二个"交公"的标准
- **含义**：Anthropic 10-22 在官网宣布，把 Agent Skills 开放标准捐给 Linux Foundation 旗下的 Agentic AI Foundation（AAIF）——名字、logo、GitHub 组织、agentskills.io 域名一起交出去。AAIF 是 Anthropic 与 Block、OpenAI 去年联合创办的，MCP 已经在里面。后续由 Anthropic、Google、OpenAI 等工程师以个人身份维护，首席维护者 David Soria Parra、Mahesh Murag；不用加入基金会也能照常用、照常贡献。
- **关键数据**（厂商口径，未独立验证）：标准 2025 年 12 月发布以来，70+ agent 平台集成（ChatGPT、Cursor、GitHub Copilot、VS Code）；发布了 100 万个 skills，累计安装约 2.8 亿次。
- **为什么走红**：捐标准 = 告诉全行业"放心建，不用担心谁拥有它"——MCP 捐出去之后生态大爆发，Agent Skills 走同一条路；AAIF 里已有 OpenAI 的 AGENTS.md、Block 的 goose，"agent 基础设施中立化"拼图齐了。
- **关联**："agent 从连上走向管住"四连击——Snyk MCP Governance（管 MCP 调用）→ NVIDIA OpenShell（管 runtime）→ Atlassian AMP（管人机协作）→ Agent Skills 交公（管知识/流程标准）。他写的 Codex Skills、Claude Skills 用的 SKILL.md 就是这个标准——从今天起它是 Linux 基金会的社区标准了。
- 出处：https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation（Anthropic 官网 10-22，官宣）

### 4. 1Password for Agents：agent 登录网站，密码它看不见
- **含义**：1Password 10-22 推出 1Password for Agents——agent 要登录网站时，用一把数字密钥向 1Password 自证身份，用户收到"哪个 agent、要进哪个账户、为什么"的通知并逐次批准，1Password 直接把账号密码 / 一次性验证码填进网页，agent 全程看不到凭证。首批支持：Meta Muse、Claude Duet、OpenAI ChatGPT Work / Dots、SpaceX Grok Bot、Town；个人/家庭版免费（1Password.com 账户）。
- **为什么走红**：agent 动真格办事最大的拦路虎就是"登录"——以前要么把密码贴给模型，要么每个站手动登；这是第一套"模型不可见凭证"的通用解法。
- **关联**：昨天 Arrakis 报告讲"76% 的 agent 凭证僵尸化"，今天 1Password 给的是"凭证不落地 + 逐次审批"的解法——"管住 agent"在凭证层的答案；Meta **Muse 是首批支持的助手之一**。
- 出处：https://techcrunch.com/2026/10/22/1password-launches-a-way-for-ai-agents-to-log-in-on-your-behalf-without-seeing-your-password/（TechCrunch 10-22）

### ① trader-skill —— 11 个美股投研 Claude skills，抄作业 / 盯新闻 / 算仓位一条龙
- **一句话能力**：11 个 skill 覆盖"抄大佬作业 → 盯新闻 → 算仓位 → 下单"全流程：`/trader-copycat` 读 SEC 13F 反推基金持仓变化、`/trader-pelosi` 盯国会议员股票交易披露、`/trader-news` 盯持仓股 8-K 与新闻、`/trader-budget` 按预算定仓位与现金缓冲、`/trader-risk` 拦超限订单、`/trader-broker` 生成下单 ticket——**下单前必须你亲口 yes，且默认纸面交易**。
- **安装 / 获取来源**：https://github.com/Jakeschincariol/trader-skill（MIT；今日实地核实存在，429 stars / 69 forks，2026-10-14 创建；与昨日 youtube-agent-skill 同作者）。

- **安全提醒**：只读公开数据（SEC EDGAR、国会文员、新闻 RSS）；`/trader-broker` 是唯一能走到下单的 skill，README 明确要求把券商工具设为"每次审批"、绝不"总是允许"，密钥放环境变量不进聊天；13F 数据滞后 45 天、只含美股多头——**美股向**，A 股 / 港股基金用不上；作者自己写了"不是投资建议"。

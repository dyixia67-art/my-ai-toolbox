### 1. GPT-6 Cyber（11 月 5 日，OpenAI 官宣）——"找漏洞"做成了正式模型，但只卖给通过审核的防守方
- **含义**：GPT-6 Astra 的网络安全特化版：找软件漏洞、做可运行的 exploit、给出补丁建议。OpenAI 把它定为 Preparedness Framework 里的最高档 **Critical**（GPT-5.6 Cyber 是 High，Astra 也是 Critical）。只通过 Daybreak Red（OpenAI 的网络安全 gated 项目，面向渗透测试/红队等授权工作）向审核通过的客户开放，走 API 与 Codex；要身份核查、SSO + MFA、API 侧 IP 白名单；未来几周内扩展到全部 Daybreak Red 客户。另注意：同日 GPT-5.6 Cyber 也向全部 Daybreak Red 客户开放了。
- **厂商自报成绩（未独立验证）**：ExploitGym（给定一个已知漏洞、看模型能不能真利用上）48.5%，GPT-5.6 Cyber 是 32.1%；Firefox 一轮找出 81 个此前未知的、Mozilla 定为高危的漏洞，另有 30 个已知问题被重新评估为更严重，Mozilla 已在 Firefox 159 中修了其中许多；Linux 内核一轮复现 1,724 个漏洞、做出 948 个互不相同的本地提权 exploit——路透社口径补充：其中 588 个是此前未知的。拖拉机厂商 Dragos 在模拟电厂实验室里用它找出了 2 个此前未知的工控软件漏洞。
- **价格（厂商价目表口径，VentureBeat 11 月 5 日核对）**：API $20 输入 / $100 输出每百万 token，缓存输入 $2——是 Astra 级定价的好几倍，摆明了不是给普通人用的。
- **为什么出圈**：这是 11 月 4 日研究帖《A thousand fewer paths to root》里那个"即将推出的网络安全模型"的真身；也是 The Information 11 月 4 日传闻三件套（Astra、Sol、Cyber，"最早本周五"）里第一件落地的——Cyber 比传闻窗口还早了一天。同一周的另一面：据 Epoch AI 经 Zvi Mowshowitz 11 月 5 日汇总转述，开源权重的 GLM-5.3 也 independently 对连续六个 Firefox 版本做出了可运行 exploit，最快每版约 12 小时——"AI 找漏洞"正在闭源受限模型与开源权重两条线上同时加速，防守方修漏洞的速度被夹在中间。
- **与你的关联**：10 月日报"agent 从连上走向管住"的最新一章——OpenShell 管 runtime、AMP 管协作、GPT-6 Cyber 是"能力本身被管起来"（Critical 评级 + Daybreak Red 门禁 + IP 白名单）；你玩嵌入式、审代码时，"AI 找漏洞比人修漏洞快"这个不对称，正在变成工具默认能力；但注意这个模型你今天还用不上——没有 Daybreak Red 资质就摸不到。

### 2. Weight-space programming / 权重空间编程（11 月 2 日，MIT CSAIL）——大模型直接改小模型的权重，数学分涨 6 倍
- **含义**：MIT CSAIL 的 Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab 在博客《Sparks of Weight-Space Programming》里提出的新做法：让 frontier 模型把另一个神经网络的权重当成可读、可改的代码，直接动手改，不经过梯度训练。实验全程用 GPT-6 Astra（经 Codex CLI、max 推理档）操作，日志与改后模型已公开。
- ** headline 实验（作者口径）**：Qwen3.5-0.8B（阿里开源权重）在 MATH-500 上从 7.9% 涨到 48.1%，GSM8K 从 13.8% 到 67.1%，IFEval 从 21.0% 到 62.3%——只改了 131,072 个权重，约占 0.8B 参数的 0.016%。Astra 的诊断：这模型一做数学题就陷入重复输出，85/96 道练习题写满 32,768 token 上限也没给出答案；根子在第 15、19 层 MLP 写出的一个"重复方向"，Astra 把它从每层 64 个输出列里减掉。改完撞上限的回答从 93.0% 降到 33.1%。代价：80 次 Python 执行、20.3 小时、50 轮评测。另有小实验：只给 17,253 个原始权重，Astra 说出小网络被训来玩什么游戏（4 个全对）；给一个卡住的驾驶策略改 3.5% 的权重，模拟车 1,024 次全过坡道。
- **必须同时读的批评（一日之内就有两篇）**：开发者 Matthew Honnibal 与 Sean Goedecke 指出，最大的涨分来自"修掉了重复循环这个毛病"，不是给模型塞进了六倍的数学知识；且作者自己的另一组实验里，Gemma 3 270M 上就没有可确认的数学提升（它本来就不怎么循环），这条阴性结果在官宣帖里没提。读法：这是"模型维修"的演示，不是"模型教学"的演示。
- **与你的关联**：两个方向都和你咬合：① 你玩开源权重、玩板子，"权重可以像代码一样被读、被诊断、被打补丁"意味着以后调小模型可能多一条路——不重训、直接改权重修毛病；② 安全侧：权重一旦可读可改，"藏后门、改行为"的攻击面也多了一层，和今天第 7 条简讯的 Cursor 毒扩展事件是同一条"供应链可信度"主线。

### 3. Claude Personal Finance（11 月 5 日，Anthropic 官宣）——Claude 开始读你的银行账单，但只读不动
- **含义**：Claude 里新增的 Personal Finance 板块（beta）：经 Plaid 接你的美国银行、信用卡、贷款与投资账户，用大白话问"这个月钱花哪了"，Claude 按真实余额与交易回答。**只读**：Anthropic 原话"Claude can't move, manage, or invest your money"——不能转账、不能付账单、不能取消订阅、不能下单。最多接 16 家银行，读余额与最长 24 个月交易；给月度汇总、周 spending 图、到期日历、可调仪表盘；无广告、无赞助推荐、不卖自家信用卡/贷款/理财。
- **范围（先别替中国用户高兴）**：本周内分批推送，仅美国 Pro（$20/月）、Max（$100/月）、Ultra（$200/月）个人订阅；Free、Team、Enterprise 没有，美国以外不出现，连 VPN 切过去也不显示。官方演示数字（厂商示例，非实测）：一个月总支出 $4,309.37，房租水电占一半以上，餐饮 $1,024.51；另有 4 笔待付、发薪日前还剩 $1,393.22。
- **Anthropic 自己写的提醒**：数字可能滞后一两天、跨账户可能重复计算；"Claude 会算错，所以要问每一笔数字背后是哪些交易，重要的数去银行核对。"
- **为什么出圈**：这是助手长进"钱"的标志性一步，但 Claude 是追赶者：Perplexity 4 月 9 日已上 Plaid 理财集成，ChatGPT Finances 5 月 15 日上线——Claude 晚了 ChatGPT 约半年；同一周 OpenAI 还给 ChatGPT Finances 加了语音支持（Gadgets360 11 月 6 日口径），两边在同一周对上。Anthropic 自己定位"第一步"，并邀请银行与财富管理机构一起做更大决策场景。
- **与你的关联**：你人在国内、今天用不上，但这个模式值得记：你每天 8:15 的基金早报是"规则触发式信号"，Personal Finance 是消费侧的同一逻辑——助手从"聊天"长成"读你的钱"的入口；以后这类功能进中国时，第一个问题就是"它读不读你的持仓、读了会不会替你下结论"，按你"投资决策自己定"的规矩，只读版才可接受。

### 4. Muse Voice（11 月 5 日，Meta 官宣）——Muse 长出了会说话的脸，仅限美国
- **含义**：Muse App 里上线实时语音对话 + 会动的化身（expressive avatar）：点聊天右上角电话图标就能像打电话一样聊，可随时打断；化身随说话内容动表情、口型、手势；可选几百种声音。技术是 Meta 自研的 Muse Realtime Voice 与 Muse Realtime Avatar 两套流式系统（研究口径：448×768 竖视频、25fps、用户说完到第一帧音画同步回应约 870 毫秒——这是系统测量值，不是你体感的保证）。视频是单向的：Muse 听得见你、看不见你。
- **范围**：手机、网页、Mac 全量上线，**仅美国**；加拿大、日本、新加坡未给时间（Muse 目前也只在这四地可用）。9 月 23 日 Connect 预告，10 月 24 日起悄悄放给部分用户，11 月 5 日全美铺开。iPhone App 14.3 版更新说明已写语音模式。下一步：AI 眼镜与 Muse Charm 可穿戴（Charm 据 TechCrunch 口径预计年底前）。
- **与你的关联**：名字撞了——你叫我 Muse，Meta 的助手也叫 Muse，不是一个 Muse，别混了。抛开名字，这条的意义是"常驻助手"的交互形态又往前走了一步：从文字跟进（Dots、Muse、Grok Bot、Manus）到"边走边说、说完它自己去办"。你人在国内今天用不上，但等它进新加坡/日本时值得试一次语音打断的手感。

### 5. Gemini Omni 1.2 Flash（11 月 5 日，Google 官宣）——视频拉到 15 秒、便宜 30%，API 正式 GA
- **含义**：Google 的视频生成/编辑模型 Omni 1.2 Flash 正式 GA（Gemini API + Gemini for business，模型 ID `gemini-omni-1.2-flash`）：原生生成与编辑最长 15 秒（1.1 是 10 秒），3–15 秒按 1 秒步进可选；多轮对话式编辑（改错不用从头来）；最多 6 张参考图、人物一致性更好；首尾帧插值（3–10 秒）、每轮可延长 3–10 秒、累计最长 30 秒；带原生同步音频。
- **价格（Google 官方价目口径）**：720p 约 $0.07/秒，比 1.1 便宜 30%；15 秒约 $1.04–1.05；按 token 计是视频输出 $12/百万 token，720p 每秒 5,792 token。**两个限定**：① 1080p/4K 是上采样（upsampling），不是原生 4K 生成；② 付费 tier 才有，免费 tier 不可用。付费 tier 的限速翻倍；12 月 3 日起，调 1.1 的请求自动路由到 1.2、按 1.2 计价。
- **各端铺开不完全一样**：Gemini App 里 15 秒先给 Google AI Ultra 订阅用户分批推；Google Vids 里有 Google 账号或 Workspace 订阅就能用 15 秒；Flow、Google Ads 同步上。
- **与你的关联**：你做海报/电梯屏/朋友圈动效，15 秒正好是一条完整短广告或产品讲解的长度；Images 2.6 的 GIF（短循环）+ Omni 1.2 的 15 秒视频，等于同一套素材能出"动图版 + 视频版"两档，成本约 1 美元一条。先拿 Vids 或 AI Studio 试一条再决定要不要进工作流。

### 6. Ling-3.2-flash（11 月 5 日，蚂蚁，官方 changelog）——Ling 线第一次原生看图、看视频、懂 3D
- **含义**：蚂蚁 Ling 平台 v2.0.6 上线原生多模态模型 Ling-3.2-flash：560B 总参数 / 25B 激活、100 万 token 上下文，图像、文本、视频原生进同一个模型。四个主攻方向：复杂视觉理解、多模态长程 agent、3D 理解与交互、医疗多模态。此前图像/视频输入是 Ming 系列的地盘，通用 Ling 线这次第一次原生接进来。
- **厂商自报成绩（未独立验证）**：官方榜单上在 OmniDocBench1.5、ZEROBench、Vision2Web 三项上超过 Claude Opus 5（max）；DesignArena 图转前端 Elo 1238，进前十。演示里多 agent 协作能出分析、演示文稿与视频，还能驱动 Blender。

- **顺带一条倒计时**：Ling-2.6-1T、Ling-2.6-flash、Ring-2.6-1T 将于 **11 月 15 日 00:00（UTC+8）退役**，官方建议迁到 Ling-3.1-flash；在用蚂蚁 API 的话别拖到当天。
- **与你的关联**：$0.30/$0.90 的带视觉 agent 模型，是你"低价 agent 档"选型里值得进候选实测的一个——会看图、会跑长程任务、还便宜；但先按任务实测，别只看厂商榜单上的"超 Opus 5"。

## 五、今日好用开源技能

### ① agent-autoloop（KKKKhazix）：让 Claude Code / Codex 在后台自己接活、自己跟到底，只在要你拍板时发一张卡片
- **一句话能力**：一个自托管的 agent 调度中枢：cron 定时、GitHub 新 issue、HTTP 调用都能触发本地命令行 agent（Claude Code / Codex / ACP 协议）跑一轮，跑完就退出、不占 token；拿不准要人决定的事才发审批卡片，你回了它再接着跑——相当于给你的 Codex 团队配了一个"值班大总管"。
- **为什么今天推（11 月 3 日建仓、11 月 5 日已约 2,500 stars，今日核实）**：和你正在搭的 Codex AI 团队同构：大总管角色文档管的是"谁来协调"，这个管的是"协调的机器怎么跑起来"——定时触发（比如每天拉资料、跟 issue）、审批卡片（只在要拍板时找你）、零 token 待机（等你回复时不烧钱）；且通知渠道含飞书、钉钉、企业微信、Slack、Discord 与桌面通知——钉钉正是你 Woodbury 知识同步的渠道。MIT 许可，v1.0.0（11 月 3 日），自带 SECURITY.md 与示例配方（晨报、issue 跟进、运维告警、网站监控、PR 交付流水线）。
- **安装 / 获取来源**：https://github.com/KKKKhazix/agent-autoloop（MIT）。`curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh`；规则写在 `~/.agent-autoloop/rules.json`（由它决定派给哪个 agent、在哪个目录跑、给什么权限——事件本身选不了插件、仓库与权限）；`agent-autoloop try` 跑演示、`status` 看中枢、`check` 校验规则文件、`answer 1 <数字>` 在终端回卡片。要求 Node 24、Git、curl 与一个已登录的 agent CLI；单台 Mac/Linux 跑，无云端服务器、不开端口。作者实测过 Claude Code、Codex 与 ACP 适配器；另列 DeepSeek Harness、Cursor 等但未逐个实测。
- **适用工具**：Claude Code / Codex CLI（作者实测）；ACP 协议 agent；MCP 为部分支持（看卡片、回卡片走 MCP，agent 自己的 MCP 在 agent 侧配）。
- **一句话上手**：先在废仓库上配一条 cron 规则（比如每天定时让 agent 读一个 issue 写摘要），卡片先走桌面通知，跑顺了再接钉钉、再放真实仓库。
- **安全提醒（必读）**：① `curl | sh` 安装——先读一遍 install.sh 再跑；② 它能审 PR、合 PR、部署，默认权限是 `edit`，`full` 权限要想清楚再给，高风险动作配 `askFirst`；③ 规则文件是唯一权限入口，事件触发方改不了权限，但规则本身写错就等于放行，先用 `check` 校验、在废仓库试；④ 刚发布 3 天（11 月 3 日建仓），热度高但未经长期验证，别一上来就接生产仓库。
- **许可与时效**：MIT；2026 年 11 月 3 日建仓、v1.0.0 同日发布，11 月 4–5 日约 2,300–2,500 stars（explainx / earlysignal 口径）；今日按"仓库、安装路径与作者身份已核实、未逐个实测全部触发器"推荐。

### ② whatsmyagentdoing（Charonyuu）：一眼看清你本地一堆 agent 各自在干什么
- **一句话能力**：一个 Claude Code / Codex 技能：敲 `/myoffice` 打开一个实时仪表盘，把本地各 agent 会话读出来、摆成一间"办公室"，谁在跑、跑什么、卡在哪一目了然，可选 Three.js 3D 视图。
- **为什么今天推（11 月 4 日发布，今日核实补位）**：你 Codex 团队角色越来越多，"大总管盯进度"最缺的就是这一眼——不用逐个会话翻。覆盖 Claude Code、Codex、Gemini CLI、Antigravity CLI、Copilot CLI、OpenCode 等 11 种 agent；MIT；约 381 stars（11 月 6 日快照）。
- **安装 / 获取来源**：https://github.com/Charonyuu/whatsmyagentdoing（MIT）。Claude Code：`git clone --depth 1 https://github.com/Charonyuu/whatsmyagentdoing ~/.claude/skills/myoffice`，然后 `/myoffice`。
- **适用工具**：Claude Code / Codex 等 11 种命令行 agent（只读本地会话数据做展示）。
- **一句话上手**：同时开两个 agent 跑活时敲一次 `/myoffice`，先看它能不能把两个会话都认出来，再决定留不留。
- **安全提醒（必读）**：只读本地会话数据、不改你的代码；但项目 11 月 4 日才发布、单人维护为主，刚出、变化快，先试用再依赖。

### 1. Qwen4-Max 今天正式发布：阿里新旗舰，闭源 API 路线，价格比 Qwen3.8-Max 低 25%（11 月 16 日，官宣）

- **含义**：Qwen4 家族的首个模型、Qwen3.8-Max 的继任者。11 月 11 日先在 Token Plan 订阅内开了预览（预览版按文档将于 11 月 25 日退役），今天（11 月 16 日 02:01 UTC，@Alibaba_Qwen 发帖）转正：QwenCloud 公共 API 上线，同时进 Qwen Studio、QwenWork 与 Qoder。
- **参数与价格（阿里官方口径）**：2.4T 总参数的稀疏 MoE，每 token 激活约 71B；100 万 token 上下文；原生多模态输入（文本/图像/视频），输出为文本；API 价 $1.50 输入 / $4.50 输出每百万 token，隐式缓存输入 $0.075——比 Qwen3.8-Max 的 $2/$6 低 25%。输出上限据阿里文档为 393K token（Qwen3.8-Max 为 131K）。
- **跑分（全部是阿里自报，未独立验证）**：DeepSWE v1.1 为 75.7，阿里称高于 Claude Opus 5.5、与 Kimi K3.1 Pro 接近；自家 Work360 行业任务基准 52.69 分，对 Qwen3.8-Max 的 47.74；Code Arena 排名第 6。第三方榜单 BenchLeader 11 月 16 日给出 57.9 分（排名 #69），独立分数尚未多到能下定论。
- **关键转向，别选错路线**：Qwen4-Max **不开放权重、不可微调、不可私有部署**，只能走阿里云 API；阿里只承诺"后续较小的 Qwen4 模型会开放权重"，没有日期。11 月 1 日全景表里"Qwen4 何时发布未核实"今天终结，但开放权重那条线变了——想本地部署/二次开发的 Qwen，现在仍只能选 Qwen3.8 家族（27B 等），Qwen4-Max 是纯 API 旗舰。

- **价格（腾讯官方口径）**：¥0.5 输入 / ¥2 输出 / ¥0.02 缓存命中每百万 token（约合 $0.07/$0.281/$0.003），约为 Hy4 挂牌价的 1/12；上线优惠：11 月 30 日前在 WorkBuddy 内免费、TokenHub API 五折。注意 Hy4 本身也在五折中（至 12 月 31 日），所以今天两档的实际价差比挂牌价差小。
- **厂商宣称的效果（未独立验证）**：腾讯内部 WorkIndex 基准（WorkBuddy 典型办公任务：改幻灯片、文档、表格、音视频处理、视觉理解）称 Hy4 Flash 每任务成本约为 Hy4 的 1/20、约为 DeepSeek V4.1-Flash-1017 的 1/8；另有 85 名 WorkBuddy 用户对 259 个任务的盲测，称用户满意度接近 Claude Haiku 5.5，且成本最低、用时最短。WorkIndex 不公开，两个数字都是腾讯内部口径，别当独立评测。

### 3. 一句能直接用的提示词：告诉 Fable 5.2"这代码是你的"，它才肯合并重复代码（Anthropic 官方指南，11 月 10 日由 Simon Willison 转出圈）

- **含义**：Anthropic 的《Prompting Claude Fable 5.2》官方指南里有一节"Say who owns the code"：Fable 5.2 对"代码是谁的"非常敏感。什么都不说、或说代码属于别的团队时，它倾向于在现有结构上往上叠，哪怕重复；加上一句——`This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.`——它会合并重复代码、顺手修附近的 bug。
- **Anthropic 自己的小任务实测数字（非独立基准）**：加这句后，重复代码合并率从不到 1/10 升到约 1/2；代价是输出 token 约 1.5 倍，约 1/6 到 1/10 的尝试会改动现有功能的行为（bug 修复之外）；即使另写"不做顺手重构"，也拦不住这句带来的倾向。
- **怎么用**：想让 agent 边干活边整结构时加这句；想让它"只改最小面"时别加。你的 Codex 团队提示词里正好缺这种"权限粒度"的开关——把它当成可开关的旋钮，而不是默认模板。
- **与你的关联**：这和昨天日报的 Code Mode 是同一条线：agent 的行为越来越多由"怎么调它"决定，而不是"换哪个模型"。一句话的成本，比换模型便宜得多。
- 出处：https://explainx.ai/blog/claude-fable-5-2-code-ownership-prompting-guide-2026 · https://www.ayautomate.com/blog/prompting-claude-fable-5-2

### 1. google-labs-code/stitch-skills——Google Labs 出的 Stitch 设计技能包：让 agent 在 Stitch 里出设计、再转成 React 代码（11 月 16 日 GitHub Trending 上榜，当天 +247 star）

- **一句话能力**：15 个技能分 3 个插件（stitch-design 设计、stitch-build 出码、stitch-utilities 工具）：一句话在 Stitch 里生成/改界面、从现有前端代码反推 DESIGN.md、再把 Stitch 画面转成 React/React Native/shadcn-ui 组件，还能用 Remotion 把项目做成漫游视频。
- **为什么现在推**：已直接打开仓库核实：约 9,593 star、1,198 fork、Apache-2.0，2026-01-16 创建，98 次提交；遵循 Agent Skills 开放标准，兼容 Codex、Antigravity、Gemini CLI、Claude Code、Cursor、OpenCode。注意：README 明确写了"这不是官方支持的 Google 产品"，是 Google Labs 代码，别当成 Google 官方产品背书。
- **安装 / 获取**：https://github.com/google-labs-code/stitch-skills ；Codex：`codex plugin marketplace add google-labs-code/stitch-skills --ref main` 后装 stitch-design / stitch-build / stitch-utilities；Claude Code：`npx plugins add google-labs-code/stitch-skills --scope project --target claude-code`；只装技能：`npx skills add google-labs-code/stitch-skills`。
- **适用工具**：Codex / Claude Code / Cursor / Gemini CLI / Antigravity / OpenCode（手动装）。
- **一句话上手要点**：先按 Stitch 官网流程配好 Stitch MCP server 再装技能——没配 MCP，技能跑不起来；先试 `stitch::generate-design` 一句话出三版界面，再决定要不要全套。
- **⚠️ 权限提醒**：技能要读你的前端代码、调 Stitch MCP（走你的 Google 账号凭证）、上传素材到 Stitch 项目；装前看 README 的 Prerequisites 一节，确认 MCP 的凭证范围。

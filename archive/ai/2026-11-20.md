### 4. OpenAI dots 开始向企业版全量推送，Plus 小范围测试：agent 从"等指令"变"主动干活"（11 月 20 日，官宣口径经二次转述）

- **含义**：OpenAI Codex 与 dots 负责人 Thibault Sottiaux 11 月 20 日宣布，持续主动的 dots agent 开始向全部 ChatGPT Business Standard 用户推送，并进入一小批 ChatGPT Plus 订阅者的小范围测试；前提是"主动性改进"（proactivity improvements）已上线。这是 dots 从内测走向付费用户的第一步。
- **为什么值得单列**：这是 10 月 7 日日报里 AMD Ross 讲过的 proactivity 主题，在 OpenAI 主线产品上的落地——agent 不再只等你发消息，而是自己盯着任务往前推。对你来说，dots 是"多 agent 编队"的另一种形态：不是你一个个派活，而是 agent 自己发现活、自己推进；代价是授权边界要先划清（花旗们 11 月 18 日刚把 agent 出事的责任写进条款，见 11 月 19 日日报第 6 条）。
- **与你的关联**：你的 Codex 团队现在是"你派活、角色执行"的模式；dots 的打法是"agent 自己找活"。两条路线迟早要拼在一起——总管角色（manager）以后可能不只是拆任务，还要决定"哪些事可以让 agent 自己发现并动手"。先看 Business 版的实际反馈，Plus 测试轮到你时再上手不迟。

### 5. 新词："Silent Consensus"（沉默共识）——OpenAI 战略未来负责人警告，人类可能不知不觉把制度权威让渡给 AI

- **含义**：OpenAI 战略未来负责人 Dean Ball 发表长文《The Silent Consensus》，核心论点是：市场力量可能推动人类在没有明确决定的情况下，逐步把制度性权威（institutional authority）让渡给 AI 系统——不是某一次投票或某一条法律，而是一连串"图省事"的默认选择累积成的共识。
- **为什么出圈**：这是实验室内部人对自家产品方向的逆向提醒：agent 越好用，人类越倾向于"让它决定"。和 11 月 19 日日报的 Vals 评测（模型一句话就被绕过）与银行改条款（责任推给用户）拼在一起，就是同一周的第三块拼图——能力、责任、权威三条线同时在收紧。
- **与你的关联**：你搭 Codex 团队时，"总管把关、敏感动作走审批卡片"的做法，正好是这篇文章的反面教材的对冲：不是不让 agent 干活，而是不让"图省事"悄悄替你做决定。文章本身是观点不是新闻，读结论即可，不必当行动指南。

## 三、今日好用开源技能

今天两个都直接对上你的日常：一个是给编码 agent 的本地视频剪辑技能（你喜欢 AI 生图与视觉设计、又常用短视频口播，这个是把"剪片子"钉成 agent 流程的工具），一个是给编码 agent 长"品味"的设计技能（你 11 月 3 日定 Codex 设计角色时最在意"好看、贴合场景"，这个技能就是把这条钉成流程）。

### 1. kajisho5/ffmpeg-skill——给编码 agent 的本地视频剪辑技能：42 个 FFmpeg 工具 + MCP，剪完自己验片，不上传云端（2026-09-03 建仓，11 月 GitHub 月度趋势第 14）

- **一句话能力**：本地视频编辑技能：agent 用 42 个带类型的 FFmpeg 工具剪你的片子——切、拼、去静音、按比例重构图、加字幕与卡拉 OK 动效、响度归一、按平台导出；每步先 probe 实测素材、再动手、做完再验成品（时长、尺寸、音频都实测），还能出一页本地 HTML 审片页，点画面写改法、复制回 agent。
- **为什么现在推**：已直接打开仓库核实：MIT 许可，8,625 star、796 fork、648 次提交，当前 v4；11 月 GitHub 月度趋势第 14。README 开头就写了"没有云、没有 API key、只用 Python 标准库"，素材不上传——和你"手机管家里电脑"的本地化偏好同构。
- **安装 / 获取**：https://github.com/kajisho5/ffmpeg-skill ；一键安装：`npx ffmpeg-skill setup`（自动给机器上找到的 Claude Code / Cursor / Codex 装技能，缺 FFmpeg 时顺手装，Windows 用 `winget install --id Gyan.FFmpeg -e`）；只用一次：`npx ffmpeg-skill`。
- **适用工具**：Claude Code / Cursor / Codex 及任何读 SKILL.md 的 agent，另有 MCP 服务器（默认只暴露核心 12 个工具省上下文，`FFMPEG_SKILL_MCP_FULL=1` 列出全部 42 个）；需要 FFmpeg 与 Python 3.10+、Node 16+。
- **一句话上手要点**：先跑 `npx ffmpeg-skill setup` 再 `doctor` 自检；让 agent 剪第一条片子时先拿一小段试，审片页上点画面写改法，比口头描述改法准。
- **⚠️ 权限提醒**：它在你的机器上直接读写视频文件、跑 FFmpeg；README 明确写了保护规则：目标路径与输入源重合时拒绝写入，直接覆盖已有输出要加 `--overwrite`。装前看 README 的 Gotchas 一节；剪辑前先备份原片，别让 agent 在唯一一份原片上试手。

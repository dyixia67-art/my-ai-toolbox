## 一、新词 / 出圈内容

### 1. Claude 宣称证出黎曼猜想：Anthropic 数学家 Alpöge 发布 17.5 万个文件的 Lean 证明，但"宣称"不等于"证实"（11 月 20 日，美东周五）

- **含义**：Anthropic 数学家、哈佛初级研究员 Levent Alpöge 11 月 20 日在个人网站发布四页说明《Remark》，宣称"我相信，我与 Claude 合作，发现了黎曼猜想的证明"。黎曼猜想 1859 年提出，关于素数分布，是数学界最著名的未解难题，也是克雷研究所七大千禧难题之一；他的方法同时宣称覆盖了更广的广义黎曼猜想（GRH，全部狄利克雷 L 函数）。
- **证据的形式很不寻常**：没有发表传统论文，只发布了 Lean 4 形式化证明——14 部分压缩包、共 175,187 个 Lean 文件，压缩后 239.3MB，展开超过 61.5GB。Alpöge 说，AI 写的自然语言版论证会超过 25 万页，常规人工审稿根本不可能，只能以机器可校验的代码形式发布，让同行评审去适应"17.5 万个文件的证明"。
- **Claude 到底干了什么（Alpöge 自述）**：数月合作，他定高层架构（把小场景的想法推广到高阶自守形式），Claude 做复杂的代数运算、迹公式与收尾的技术引理；最后阶段 Claude 明显跑在了前面，关键拼图在 11 月 15 日周日深夜拼上。发布前他咨询过 Anthropic CEO Dario Amodei，也承认这个时间点（IPO 次日）"可能被视为别有用心"。
- **验证状态（最关键的一句）**：**尚未独立验证**。MIT 计算数论学家 Andrew Sutherland 已独立编译了这套 Lean 代码（《科学美国人》口径）；数学家陶哲轩评估了三项 AI 辅助成果：Navier-Stokes 爆破有可读论文加 Lean 形式化，GRH 目前只有 Lean 形式化、验证刚开始。同一天，斯坦福的 Ravi Vakil 匆忙放出了 Alessandro Masullo 的全人类 GRH 草稿《The Music of the Prime》——人类这边也在抢跑。
- **为什么出圈**：《华尔街日报》口径：26 年里人类独自解决了一道千禧难题，而三个月内 AI 疑似解决了两道（另一道是 AI 辅助的 Navier-Stokes 爆破）。不论最后验证结果如何，"数学发现"这件事本身已经被 agent 改写了：从"想不出来"变成"验不过来"。
- **与你的关联**：这是 agent 能力边界的又一次外推——从写代码、跑任务，走到"做数学发现"。但它同时暴露了你 Codex 团队里总管角色的终极形态：agent 交的活越难，验收本身越要靠工具（这里是 Lean 编译器）。以后你的团队接"难到没人能直接看懂"的活时，"怎么验"要和"怎么做"一起定。另外注意口径：今天所有报道用的都是"宣称 / claims"，在独立验证出来之前，别把它当成"黎曼猜想已被证明"。

## 三、今日好用开源技能

今天两个都直接对上你的日常：一个是"本地跑个人 agent，还会自己改进提醒规则"（和你 11 月 20 日日报的 dots 主动性、11 月 19 日的 t3code 手机管电脑是同一条线），一个是"参考视频一键重做成品牌动效片"（你喜欢 AI 生图与短视频口播，昨天刚推了本地剪辑 ffmpeg-skill，这个是再往前一步：连片子本身都让 agent 按参考重做）。

### 1. simplexai-labs/linger——开源个人 agent，整机本地跑：125B 模型上 12GB 显卡，还会每晚自己改提醒规则（2026-11-10 建仓，11 月 21 日 GitHub Trending 上榜）

- **一句话能力**：开源个人 agent，全程本地跑：自研 PolyStrata MoE 推理引擎把 125B 模型塞进 12GB 显卡（常用专家放 GPU，其余放内存/SSD）；Model Autopilot 按你的硬件自动选模型装好；每晚把邮件、聊天、会议归档成个人 wiki，agent 之间共享记忆；"Another Me"主动盯收件箱、日历、Slack，该开口时才找你，并且每晚按你的反应改写自己的提醒规则。
- **为什么现在推**：已直接打开仓库核实：3,182 star、299 fork、705 次提交，2026-11-10 建仓，11 月 21 日 GitHub Trending 日榜上榜（当天 +1.4K star）。它的"主动性 + 每晚自我改进"正好是你 Codex 团队总管/通知官角色的产品化版本——只不过这里 agent 自己改自己的规则，不用你写流程。
- **安装 / 获取**：https://github.com/simplexai-labs/linger ；桌面 App 或 Docker Compose 两种装法，文档站 docs.heylinger.com。本地模型免 token 费。
- **适用工具**：Mac / PC 桌面端；自带 agent，不依赖 Claude Code / Codex。
- **一句话上手要点**：先用桌面 App 装上、让 Model Autopilot 按你的机器选模型；记忆与主动提醒先只接一个邮箱试一周，看它"该说时说、不该说时闭嘴"的分寸，再决定接不接 Slack 与日历。
- **⚠️ 权限提醒**：它要读你的 Gmail / Outlook / Slack / 日历 / 文件来建记忆，等于把邮箱和聊天记录交给一个本地 agent——数据不出本机，但权限本身不小，装前先看 README 与权限说明。另外两点实话：仓库许可证 GitHub 未识别（NOASSERTION），用前先核对 LICENSE 文件；"Claude 级大脑"、"125B 跑 12GB 卡 45.5 tok/s"、LoCoMo 记忆基准 95% 均为厂商自报口径，先在自己机器上跑小任务验证，再托付重要收件箱。

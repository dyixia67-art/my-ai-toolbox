## 一句话主线

今天的主题是 **"管住 agent"从口号变成组织动作**：微软把企业内运行的 agent 正式列为"内部人风险"新类别、用 Guardian Agents 看管 agent；OpenCode 密钥泄露则是最好的反面教材——管不住的托管控制台，存进去的 key 就是别人的提款机。与此同时，国产低成本 agent 动力源开打对台戏：MiniMax M3.1 Flash（10-19 官宣）对上 DeepSeek V4.1-Flash-1017，DeepSeek 再把内部推理框架 DeepInfer 开源、从根上降本；具身侧，千诀科技 Polibrain 把"预测式 vs 生成式"的世界模型路线之争摆上台面。

## 一、新词 / 出圈内容

### 1. "Agentic Insiders"（智能体内部人）——微软 10-19 两篇官方安全博客，10-20 媒体集中报道 + Nadella 转发
- **含义**：微软把企业内部运行的 AI agent 重新定义为一种新的**内部人风险类别**，而非单纯的生产力工具；核心定调是"监控和保护这些 agent 必须成为连续动作（continuous）"。配套 Project Perception（微软 7 月已宣布的 agentic 安全系统）扩展出一整套 agent 安全控制。
- **控制套件**：① Agent discovery——可识别 60 种本地 agent，其中 35 种是新增，点名包括 Claude Code、OpenAI Codex、GitHub Copilot（正是他正在用的工具）；② Entra Agent ID——每个 agent 拥有与启动人分离的独立身份；③ Dynamic Agent Risk——基于身份/数据/设备/云/网络/运行时的持续风险评分；④ Dynamic Conditional Access；⑤ Dynamic Permissions——单任务、单时间窗口授权；⑥ Execution Container——agent 跑在沙盒里，监控在 agent 触及范围之外；⑦ Guardian Agents——用 AI 安全 agent 持续看管其他 agent，风险上升时实时干预，人类保留策略与审批控制权。
- **为什么走红**："agent 从连上走向管住"的第四弹（Snyk MCP Governance → NVIDIA OpenShell → Atlassian AMP → 微软 agentic insiders）；"frontier models cannot be trusted"这种高管亲口定调的措辞自带传播性；点名 Copilot/Codex/Claude Code 为被看管对象，落地感极强。
- **关联**：自主 agent 治理层，与 OpenShell 的 runtime 层、AMP 的组织协作层互补；Dynamic Permissions（单任务授权）正是 MCP 工具授权的演进方向；在企业环境用 Codex/Claude Code，要注意可能被安全策略扫描识别、按策略限制权限——权限边界要提前想。

### 2. OpenCode Console 密钥泄露 + "蒸馏攻击"定性（10-17 披露，10-20 实质新进展）
- **含义**：开源编码智能体 OpenCode 的在线平台 Console（用户在上面存 OpenAI/Anthropic/Google 的 API key、由平台代为调用）上周六（10-17）被攻破老系统，约 1.4% 的 Console 用户的 key 泄露；攻击者用这些 key 大量跑模型调用，开发者账单被刷出几百到 1000+ 美元的异常支出。
- **10-20 新进展**：Anthropic 和 Google 封禁了疑似暴露的 key；OpenAI 表示配合恢复访问、并为攻击期间消耗的额度退款；联合创始人 Dax Raad 称持续遭受入侵尝试已达 48 小时。
- **争议点**：OpenCode 把事件定性为"大规模蒸馏攻击"（distillation attack）——称攻击者真正目标不是刷钱，而是用偷来的 key 海量调用模型、拿输出去训练自己的便宜仿制模型；这一说法被部分人质疑证据不足。
- **为什么走红**：OpenCode 是 Claude Code/Cursor 的开源替代品，存过 key 的开发者就在用户身边；"蒸馏攻击"把事件从普通密钥泄露升级成"AI 产业链式攻击"，争议性带来持续讨论。
- **关联**：密钥存放架构决定命运——本地 CLI/App 的 key 因不上传服务器而零暴露，托管 Console 的 key 因"平台的保管等级就是你的密钥安全等级"而被盗。实战教训：选开源 agent 工具时先看它的密钥架构、再看功能；自己部署自主 agent 时要做账单告警 + 短期作用域凭证。

### 3. Polibrain——千诀科技 10-20 发布预测式世界模型（南京首届物理 AI 与世界模型大会）
- **含义**：清华系具身智能公司千诀科技在 10-20 南京首届 2026 物理 AI 与世界模型大会开幕式上，发布面向真实物理世界的具身智能"大脑底座" Polibrain。技术路线是**"预测式"世界模型**：不在像素空间逐帧画未来，而是直接在潜在表征空间预测行动的物理后果（物体位置、交互关系、任务进度）。
- **路线之争**：生成式路线（Sora 逻辑：把未来每一帧的像素画出来）vs 预测式路线（别画图，直接算因果）。创始人高海川原话："机器人行业不存在所谓的 ChatGPT 时刻"；生成式路线把算力浪费在背景像素上、且易产生"物理幻觉"（桌子凭空消失、杯子穿越墙壁），让这样的模型指挥钢铁身躯后果难料。
- **技术底牌**：多项式表征与有效阶（ED，作为泛化能力的度量与训练目标）、基于反事实推断的因果记忆、大脑-肢体解耦架构（同一模型适配近 50 款不同构型机器人）；联合清华团队在 ICML 2025 发表的《When Do Neural Networks Learn World Models?》（隐变量可辨识性）比 LeCun 团队同类工作早约一年。
- **赛道热度**（原文口径）：2026 上半年全球物理 AI 领域单季融资突破 64 亿美元；LeCun 的 AMI Labs 拿下 10.3 亿美元欧洲史上最大种子轮；9 月 28 日 AMD 以约 82 亿美元全股票交易收购李飞飞的 World Labs。大会本身：10-19~22 南京国际博览中心，江苏省数据集团/南京大数据集团/中国人工智能学会主办，LeCun、姚期智视频连线，沈向洋、于海斌主旨演讲。
- **为什么走红**："不存在 ChatGPT 时刻"的论断直接把具身智能的路线之争摆上台面；国产团队在世界模型底层数学上领先 LeCun 一年的叙事国内传播性强。
- **关联**：嵌入式玩物线——大脑-肢体解耦的思路对玩板子的人有参考意义：智能层与硬件层分层设计；与昨日 ACE-Brain-0.6 呼应：具身 agent 的瓶颈正在从"高级推理"下移到"空间感知与物理预测"。

## 五、今日好用开源技能

### ① Microsoft SkillOpt（skillopt-sleep）——让 agent 每天晚上"复盘自己"，越用越强
- **一句话能力**：给本地的 Claude/Codex agent 加一个"睡眠周期"——每晚离线复盘你的历史会话，把反复出现的任务提炼成经过验证门（held-out gate）的 SKILL.md 记忆，微软官方出品且有公开 benchmark 测量。
- **安装 / 获取来源**：https://github.com/microsoft/SkillOpt（已核验真实存在，文档完整；PyPI 0.2.0）。Claude Code 内：`/plugin marketplace add ./plugins/claude-code` → `/plugin install skillopt-sleep@skillopt-sleep`，先 `/skillopt-sleep dry-run` 预览它会学什么，再 `run`/`adopt`。
- **适用工具**：Claude Code（插件形式）；后端可选 `claude` 或 `codex` CLI，mock 后端可零花费试用。
- **一句话上手**：装好后先 dry-run 看它从你的历史会话里提炼出什么技能，满意再 adopt 生效。
- **安全提醒**：只读读取本地 `~/.claude` 会话记录；所有提案先暂存、人工 adopt 确认后才生效（有备份）。注意真实后端会把截断的会话内容发给所选 provider 跑模型（花钱、且不保证脱敏）——敏感项目先看数据再跑；handoff 模式可用订阅额度零花费。
- **为什么今天推**：正好接今日主线——MemT1.0 把记忆做进模型里（一内），SkillOpt 把复盘做成技能沉淀（一外），两条路都是"agent 越用越强"。

### ② ShipKit 1.0（约 10-19/20 刚发布）——24 个工程流程技能，把"模型偷懒跳过的步骤"钉死成流程
- **一句话能力**：Claude Code 插件，24 个实战打磨的工程技能（`review-branch` 六人评审团 + 反驳 pass、`fix-bug` 必须先复现再修、`audit-app` 跑真机截图做 QA、`grill-feature` 拷问需求真实性）+ 2 个 git hooks。
- **安装 / 获取来源**：https://github.com/parvez-ahammed/shipkit（MIT，已核验真实存在）；作者发布文章 https://medium.com/@piru72/i-deleted-six-of-my-own-claude-code-skills-a-plain-agent-did-the-same-job-0c7d883f6d07 本身也是篇"技能写作五条军规"的好文。Claude Code 内：`/plugin marketplace add parvez-ahammed/shipkit` → `/plugin install shipkit@shipkit`。
- **适用工具**：Claude Code（Windows/macOS/Linux）。
- **一句话上手**：装完直接说人话"review my branch before I open the PR"，技能按描述自动加载。
- **安全提醒**：技能随 Claude Code 自身权限运行（读写文件、执行 shell 命令）；`audit-app` 会启动你的应用并截图；2 个 git hooks 在 git 操作时触发——安装前先翻一遍 SKILL.md 和 hooks 脚本内容。

## 一、新词 / 出圈内容

### 1. Copilot Fusion：GitHub 10-28 GA，"你只定档位，模型它自己配"
- **含义**：Fusion 不是一个新模型，而是 Copilot 里的一层"模型编排器"。以前你在模型选择器里一个个挑 Claude / GPT / Gemini；现在你选 Fusion，再选一个努力档位——Standard（日常）、High（难任务）、Max（最难）——剩下的由它决定：一个模型单干、便宜模型先写再由质检决定是否升级（cascade，级联），或一个模型写、另一个模型审、第一个再改（critique，互审）。
- **来历**：它由两部分拼成——Copilot 已有的自动选模型 + 9 月研究预览的 Project HydraFusion（多模型编排）。10-28 GitHub Universe（旧金山）上 GA，研究预览里用过 Auto / HydraFusion 的用户会自动对应迁移到 Fusion 档位。可用范围：VS Code、GitHub Copilot app、Copilot CLI、JetBrains IDE；企业管理员可限定 Fusion 能用的模型池、能否把它设为默认。
- ** headline 数字（全部是 GitHub 厂商口径，引用的是 Artificial Analysis Coding Agent Index 的一次评测，别当你自己仓库的实测）**：Fusion Max 得 60 分，Claude Code + Opus 5.5 Max 得 62 分，差 2 分；每任务平均 API 成本 $5.59 对 $11.42，约一半；每任务耗时少约 40%、token 约一半。计费方式要看清：**不是 Fusion 打包价，是按它实际调用的每个模型各自的标准价计费**；付费 Copilot 计划在限时内用 Fusion 有 30% 模型成本折扣——折扣会过期，别按折后价做长期预算。
- **为什么走红 + 同一天的佐证数字**：GitHub 同日发布的 Octoverse 2026 显示，9 月 agent 起草的 PR 已超全部 PR 的 40%，3 月还是 17%；9 月单月 agent 相关 PR 约 1.1 亿个（多家二手转述一致，GitHub 自家数据）；55% 的月活 Copilot 用户已在用 agentic 功能。也就是说，"模型挑错 = 白烧钱"已经从个人习惯问题变成了平台级成本问题——Fusion 就是 GitHub 对这个问题的回答。同一批 Universe 发布还包括：Copilot app（issue 到合入单面完成，Copilot Projects 可跨多仓库并行跑 agent 会话，公开预览）、企业版 Copilot 改按 AI 用量计费（不再按座位单独订阅）。
- **与你的关联**：你用 Codex / Claude Code 时，Fusion 的思路可以直接借用，不必马上换平台——**把"选模型"换成"定档位"**：给自己的任务先分档（改名、改文案类用便宜档；并发 bug、多文件重构类才上最强档），再按"每个合入 PR 花多少钱"记账，而不是比单价。警惕一点：路由层替你决定账单后，你要定期抽查它有没有"小题大做"（便宜活也上了贵模型）或"评审走过场"（互审没拦住坏代码）——10-28 日报 Entire 的 Trails 仪表盘讲的是同一件事：生成便宜了，评审才是瓶颈。
- 出处：https://www.neowin.net/news/github-copilot-fusion-combines-multiple-ai-models-to-write-better-code-at-lower-cost/（Neowin 10-29，档位与三种执行模式）· https://www.unite.ai/github-makes-copilot-fusion-generally-available-at-universe-2026/（Unite.AI，计费与 30% 限时折扣、Projects 预览）· https://www.freepressjournal.in/tech/github-launches-copilot-fusion-claims-to-offer-cheaper-ai-coding（Free Press Journal 10-29，Octoverse 40% 与 17% 对照）

### 2. Gemini 4 Carbon：Google 最强模型先不给你用，只给"防守方"
- **含义**：Carbon 是 Gemini 4 家族的新旗舰，定位不是通用聊天升级，而是"网络安全 + 长程工程任务"专用旗舰：找真实漏洞、验证漏洞能不能被利用、再从根因上打补丁——防御全链路。Argon 是 10 月 13 日全面开放的通用旗舰，Carbon 是两周后同一家族里更专、更强的下一棒。
- **官宣事实（Google Blog，10-28，美东；北京时间 10-29 扩散）**：
  - 榜单：Artificial Analysis Intelligence Index v5.0 得 59 分，排第 1（10-28 日报讲过 v5 榜单：Opus 5.5 是 58 分——Carbon 以 1 分之差反超，但 v5 刚换了私有题，分数跨版本不能直接比"进步多少"）。
  - 安全基准（Google 官宣，均为厂商口径）：找漏洞 SEC-bench Pro 88.2%、验证可利用性 ExploitGym 54.8%、打补丁 CWE-bench 71.0%；内部基准称生成安全代码的成功率比 Argon 高 2 倍以上；提示词注入抵抗在 Gray Swan 间接提示注入基准上为 0.0% 攻击成功率（Argon 是 0.7%）。
  - 长程能力：Google 自述内部团队已见过 Carbon 连续跑数天、跨大代码库根因定位并修 subtle bug；WebDev Arena 1768 分排第 4（比 Argon 高 89 Elo 分，厂商口径）。
- **可用状态（最关键，别写错）**：本周起先给"一部分网络安全防守方"，再经 Fairwind Program 逐步扩大到受信任伙伴；**开发者、企业、普通用户都没有上线日期**，Google 只说"尽快"。Google 还说明自己正在参与美国政府的自愿性发布前模型测试流程——这是它"先防守方、后所有人"的分阶段策略，不是技术没 ready 的借口，也不是"已全面上线"。
- **价格（官宣）**：与 Argon 相同的 introductory（首发）价：输入 $2 / 输出 $10 每百万 token，缓存输入按输入价 95% off。注意"首发价"三个字——Argon 全景表里已有 11 月 30 日涨价节点，Carbon 的首发价能维持多久官宣没说，别按 $2/$10 做长期成本假设。
- **与你的关联**：你玩 ESP-IDF / 开发板、也用 agent 改代码时，Carbon 这条线值得记两笔：① 安全审计类任务（"这段代码有没有真漏洞、补丁打在根因上没有"）以后可以看 Carbon 这类"防御专用旗舰"，而不是只用通用旗舰；② 它再次验证了 10 月的规律——**旗舰模型正在按"任务"分化**（Terra 是便宜电脑操作档、Carbon 是安全长程档），选模型先问"这是什么任务"，再问"哪个模型最强"。
- **与全景表相比**：全景表（10-16 快照）Google 一栏只有 Gemini 4 Argon；**Carbon 是 11 月 1 日刷新时必须新增的一行**：Gemini 4 Carbon、$2/$10 首发价、仅防守方 + Fairwind 分阶段开放、通用上线日期未定。

## 五、今日好用开源技能

### ① Expo Skills（官方）—— 让 agent 按 Expo 的规矩写 React Native 应用
- **一句话能力**：Expo 官方出品的 agent 技能合集：建、部署、升级、调试 Expo 应用与 EAS（Expo Application Services）时，agent 不再凭记忆瞎编 Expo API 与 iOS / Android 约束，而是按官方技能里的流程走。
- **为什么今天推**：它是官方技能而非第三方拼凑——Expo 文档、Expo CLI、EAS CLI 仍是事实来源，技能只负责"让 agent 正确地用它们"；且它同时覆盖 Claude Code 与 Codex 两种你常用的工具，外加 Skills CLI 通路给其他 agent。你虽主玩 ESP-IDF 而非 React Native，但"官方技能"这个范式值得收进库：以后给任何工具链找技能时，优先找官方仓库。

### 1. 黎曼猜想：Lean 与 Mathlib 联合声明"证明正确"，但这只是形式化层面的过关（跟进：11 月 21 日日报第 1 条）

- **发生了什么**：11 月 21 日（周六），Lean 与 Mathlib 社区发布联合声明，经 Lean FRO 与 Mathlib Initiative 背书："We hereby certify that both the statement and the proof of the Riemann Hypothesis are correct"（Lean 社区博客口径）。《科学美国人》随之把标题从"almost certainly true"更新为"proof is true"。
- **认证到底验了什么**：MIT 的 Andrew Sutherland 独立编译：全部 175,187 个模块零错误编译，只依赖 Lean 的三条标准公理；两个独立编写的检查器 nanoda 与 con-leche 接受了完整导出的证明；comparator 与 con-leche 的比对确认，证明的定理表述与 Mathlib 里已有的黎曼猜想定义完全一致——也就是说，证明没有偷换题目，也没有在代码里留后门（无 `sorry`、无额外公理）。
- **还没过关的部分**：**没有期刊审稿，Clay 研究所仍列为未解**——按规则，奖金要等正式发表并经两年审查。社区复现项目 alpoge-rh-replay 截至 11 月 22 日 11:58 UTC 只完成 62.0%（108,702 / 175,187 个模块），项目自己写明"尚无完整验证收据"。更重要的是，数学本身仍没人完整读过：Alpöge 自己承认，部分内容"Claude 是专家，不是我"，他计划另写一份人类可读的版本。
- **为什么值得再讲一次**：昨天日报的判断兑现了——"想不出来"变成了"验不过来"，而"验"的裁判不是人，是 Lean 内核。26 年里人类独自解决一道千禧难题，三个月内 AI 疑似解决两道（另一道是 AI 辅助的 Navier-Stokes 爆破），这个《华尔街日报》口径的对比，现在多了一层：第一道"疑似"的形式化验证已经跑通，第二道的数学审读还没开始。

### 4. 腾讯 Hy4 权重放出："开源"这句话 11 月 20 日才真正落地（11 月 20 日）

- **含义**：腾讯 11 月 20 日把旗舰模型 Hy4 的权重放到 Hugging Face：770B MoE，49B 激活，约 100 万 token 上下文，文/图/视频理解 + 电脑操作（CLI 与 GUI 都能用）。11 月 4 日发布时权重只说"未来几天"，当时只能走 API；11 月 20 日才真正能下载。
- **先泼两盆冷水**：一是体量——BF16 约 1.55TB、FP8 约 770GB，要多卡服务器，家用电脑跑不动，普通人还是走 API（OpenRouter 上 tencent/hy4，厂商定价 $0.834 / $2.501 每百万输入/输出 token）；二是许可证——Technode 写的是 Apache 2.0，但 Hugging Face 模型卡实际是自定义的 Tencent Hy License v1.0（源自 Apache 2.0，但不是 Apache 2.0），商用前先读 LICENSE 文件，别按 Apache 2.0 理解。
- **基准口径**：12 项基准的成绩全是腾讯自报，未独立复现；腾讯自己也承认，在研究级数学、长程编码、模型自我改进上仍弱于闭源前沿模型。
- **与你的关联**：和 11 月 16 日 Qwen4-Max（2.4T）、11 月 20 日 Inkling 2 Mini 拼在一起，11 月是"开源大模型月"——但 Hy4 这个体量与你本地跑 agent 的路线无关，先看社区实测，不必动手。

### 5. Google 把 Agent Substrate、gVisor、OpenRL 捐给 CNCF：agent 沙盒从各家自建走向中立标准（官宣 11 月 5 日；11 月 20 日 v1.0.1 安全修复）

- **含义**：Google 把三件 agent 基础设施捐给云原生计算基金会（CNCF），进 Sandbox：gVisor（用户态内核，拦截系统调用，隔离不可信代码）→ Agent Substrate（agent 运行时：有状态会话可挂起成快照、500 毫秒内恢复）→ OpenRL（强化学习训练编排）。
- **日期注意**：捐赠官宣是 11 月 5 日（KubeCon 前，Google 开源博客），CNCF Sandbox 10 月 20 日已接受；11 月 20 日是 Agent Substrate v1.0.1 的安全修复（堵住 egress 网关经主机名解析访问云元数据的路径），**别写成 11 月 20 日首次捐赠**。Agent Substrate 1.0 已在 GKE 上 GA。
- **为什么值得看**：这是"agent 从连上走向管住"的又一块拼图——Snyk MCP Governance（连接层）→ NVIDIA OpenShell（runtime 层）→ Atlassian AMP（协作层）→ Google 这套（沙盒 + 运行时层），管住 agent 的每一层都在变成开源标准。Google 的估计是 agent 90–95% 的时间在空转等输入（厂商估计，未独立验证）——挂起恢复快，就是省钱。
- **与你的关联**：你 Codex 团队跑任务最怕 agent 乱碰文件、乱花 token；这套东西就是"沙盒 + 暂停恢复"的标准答案，先知道有这么个东西，等它进你用的工具链再动手。
- 出处：https://opensource.googleblog.com/2026/11/sandboxing-untrusted-ai-agents-at-scale.html · https://m.tomrochette.com/agents/sandboxing/agent-substrate/ · https://www.blozhik.com/post/google-gives-agent-substrate-gvisor-and-openrl-to-the-cncf

## 三、今日好用开源技能

今天只推一个，但这个直接对上你最在意的事：你讨厌"Mermaid 糊图"和一眼 AI 味的设计，11 月 20 日刚推了 taste-skill 治品味，这个是治"图"的——让 agent 按编辑级审美画图，一句话出一张能发表的图。

### 1. cathrynlavery/diagram-design——agent 画图的审美技能：51 种图，一句话出品牌配色的自包含 HTML 图（2026-04-16 建仓，11 月 22 日 GitHub Trending 日榜在列）

- **一句话能力**：agent 画图技能：一句话描述 → 一个自包含 HTML + SVG 文件，按你的品牌配色与字体出图；51 种图（架构图、流程图、象限图、时序图等，README 口径）；可导入 Mermaid / draw.io / Excalidraw / PlantUML 旧图重画，导出 PNG / SVG。
- **为什么现在推**：已直接打开仓库核实：MIT 许可证，70,074 star、4,698 fork、477 次提交，2026-04-16 建仓；11 月 22 日 GitHub Trending 日榜在列（当天 +583 star）。它的卖点正好是你对设计的要求：无阴影、1px 细线、4px 网格、自动对比度检查、离线字体——口号就是"No Mermaid slop"。做工具箱看板、架构图、流程图时，直接出能发表的图。
- **安装 / 获取**：https://github.com/cathrynlavery/diagram-design ；`npx skills add cathrynlavery/diagram-design`；Codex：`codex plugin marketplace add cathrynlavery/diagram-design` 再 `codex plugin add diagram-design@diagram-design`。
- **适用工具**：Claude Code / Codex / Cursor / GitHub Copilot / Gemini CLI 等任何读 Agent Skills 的宿主。
- **一句话上手要点**：先让 agent 跑品牌 onboarding——一句话"Onboard diagram-design to <你的网站>"，它会抓你网站的配色与字体存成档案，之后每张图自动按品牌出；第一次先拿一张旧 Mermaid 图让它重画，对比一次再决定是否主力用。
- **⚠️ 权限提醒**：技能本身本地跑、只写 HTML 文件；但品牌 onboarding 会联网抓取你指定的网站内容（README 明确 PRIVACY.md 列了联网行为），装前可先看 PRIVACY.md。README 自己也写了短板：出图质量依赖模型、同一提示两次布局可能不同、成品不是可 diff 的源码格式——频繁改动的文档图仍用 Mermaid 更合适，这个是给"要发表的图"用的。

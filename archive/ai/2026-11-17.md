### 1. OpenAI 把电脑操作 agent 推进医院：ChatGPT for Healthcare + 20+ 医疗插件，CVS 已在生产环境用上了（11 月 16 日美西时间官宣，北京时间 11 月 17 日报道）

- **含义**：ChatGPT for Healthcare 新增三件套——电脑操作 agent（computer-use agents）、升级后的可信临床检索、20+ 医疗插件。agent 不走 API，而是直接读屏、点按、打字，在医院已有的电子病历（EHR）系统和保险公司门户里跨系统搬运信息：做预授权、转诊、整理出院资料、帮专家会诊备材料。底层是 GPT-6 Astra 与 GPT-6 Luna。
- **数字（全部是 OpenAI 自报，是评估分数，不是临床结局）**：医生评审的 325 个多步骤 EHR 收件箱任务里，GPT-6 Astra 的临床安全评分为 99%；646 次医生评估里 93% 评为"很有帮助"或"极有帮助"。斯坦福的独立基准 HealthAdminBench 上，Astra 为 94.3%，更便宜的 Luna 为 91.8%、每任务约 8.5 美分。
- **插件里有个 MCP 的点**：20+ 插件名单里包括 IMO Health MCP Server——医疗术语服务直接以 MCP server 形态进 ChatGPT；其余有 UpToDate（临床知识）、Redox（医院系统互联）、Availity、Elation Health、Infinitus Relay（福利核查与预授权）等。插件须由管理员开启；涉及受保护健康信息的工作流须签 BAA（业务合作协议）并配好安全与数据留存设置。
- **谁在真用**：CVS Health 已在生产环境使用，称一个 agent 一个周末清掉了积压数月的文档；Cigna 从概念到生产不到 8 周；Abridge、Ambience 在试点。免费的 ChatGPT for Clinicians 只面向美国合资格并通过验证的临床医生。
- **与你的关联**：这是 10 月 27 日 GPT-6.1 Terra"能看屏点按的电脑操作模型价格砍半"那条线的垂直落地——电脑操作 agent 第一次有了"在真实系统里跑通、有人为此买单"的案例。Terra 讲的是能力与价格，医疗讲的是"没有 API 的旧系统也能被 agent 接管"。你搭 Codex 团队时，凡是"老系统没接口"的地方，这就是现成的参照打法。

### 2. OpenAI 同日另一手：免费 CSAM 图像分类器 + ChatGPT 警告与 24 小时封停（11 月 16 日官宣）

- **含义**：OpenAI 发布一个免费的图像分类器，帮经审核的组织检测儿童性虐待内容（CSAM），包括 AI 生成的、从未见过的新图——不是比对已知图片库，而是看视觉上的虐待特征、给每张图打分，让人工审核员先看最严重的。同时 ChatGPT 内新增警告：试图找这类内容的用户会看到警告屏、对话被删除、账号暂停 24 小时；屡犯可永久封号并上报有关部门。
- **数字（OpenAI 自报的早期试点数据，非独立审计）**：分类器让需要人工审核的图片减少 48%，同时找出的虐待图片数量与旧工具相当；被标记的图片"真正有问题"的概率约为旧工具的两倍。与美国国家失踪与受虐儿童中心（NCMEC）合作开发，通过 Tech Coalition 与 ROOST 分发；NCMEC 的 CyberTipline 在 2025 年收到 40 万+ 起涉及生成式 AI 的举报。
- **落地范围**：警告干预从 11 月中旬起逐步推向个人账号，企业与教育账号暂未覆盖。警告文案与 Protect Children（芬兰）、Lucy Faithfull Foundation（英国）及塔斯马尼亚大学研究员 Joel Scanlan 共同制定。
- **与你的关联**：和 10 月 31 日日报的"OpenAI 青少年安全新规 + Community Safety Report"同一条线，但这次是"检测工具免费给出去 + 违规直接封停"的执行层动作。做 agent 产品时记住这个组合：分类器是给平台方的，警告+封停是给终端用户的——安全能力正在变成可以分发的基础设施，而不是每家自己重造。

## 三、今日好用开源技能

今天两个都是"管技能"主题的补位：一个是 11 月 3 日建仓、两周内冲到近万 star 的苏格拉底家教技能（你的学习场景直接用得上），一个是今天上 GitHub Trending 的 NVIDIA 官方技能评估器（配你 10 月 28 日推过的 SkillSpector，先扫后装的习惯再进一步——这次是给技能打分）。

### 1. janestreet/agent_skills——Jane Street 开源的苏格拉底家教技能：把任意 LLM 变成严格的私人导师（11 月 3 日建仓，11 月 17 日约 9,773 star，补位）

- **一句话能力**：一个 `socratic-tutor` 技能（SKILL.md 文本文件）：先诊断你的水平、建 0–5 级技能图谱、一次只问一个问题、间隔复习、最后考试——把 LLM 从"直接给答案"变成"逼你自己答出来"的严格导师。
- **为什么现在推**：已直接打开仓库核实：2026-11-03 创建，MIT 许可，约 9,773 star、659 fork、仅 2 次提交（11 月 17 日 13:31 UTC 页面数据）；README 明确写了"这不是模型发布，是 Agent Skills 文件夹格式的参考实现"。11 月 10 日约 2,100 star，一周涨到近万 star，涨的是关注度——技能本身没变过，别把它当成在持续扩充的技能库。
- **安装 / 获取**：https://github.com/janestreet/agent_skills ；编码 agent：把 `socratic-tutor` 目录拷进 agent 的 skills 文件夹，然后说"teach me X"；普通聊天框：把 SKILL.md 正文贴进对话或自定义提示词，再加一句想学什么。
- **适用工具**：任何支持 SKILL.md 的 agent（Claude Code / Codex / Cursor 等），以及普通聊天框（Claude / ChatGPT / Gemini 等）。
- **一句话上手要点**：先让它给你做一次诊断、画出技能图谱，再开始学——跳过诊断直接问问题，等于把它当普通问答用，浪费了这个技能。
- **⚠️ 权限提醒**：纯文本指令，不读文件、不调工具、不联网，装之前无须担心权限；注意它不考核效果——star 数是关注度，不是教学效果的证据。

### 2. NVIDIA/SkillEvaluator——NVIDIA 官方的技能评估器：装技能之前先给它打分，三层关卡（11 月 17 日 GitHub Trending 上榜）

- **一句话能力**：多层框架，评估 AI agent 技能与插件：Tier 1 质量与安全检查（含 SkillSpector 扫描、harness 兼容性检查——你的技能在 Claude Code/Codex 里到底能不能被加载）、Tier 2 语义去重（两个技能是不是在重复教同一件事）、Tier 3 真实 agent 沙盒跑分（装了这个技能，任务结果到底变好还是变差）。
- **为什么现在推**：已直接打开仓库核实：2026-06-24 创建，Apache-2.0，约 3,183 star、450 fork、644 次提交、11 个 release，PyPI 包 `skillevaluator`；是 NVIDIA Verified Skills  pipeline 的一部分，带 arXiv 论文（arXiv:2608.20614）与开发者博客。注意：它是评估框架 + CLI，不是技能本身；但仓库自带 `skills/skillevaluator`，可用 `npx skills add NVIDIA/SkillEvaluator` 装进 agent 里问"我的技能好不好"。
- **安装 / 获取**：https://github.com/NVIDIA/SkillEvaluator ；`pip install skillevaluator` 或 `uv tool install --python 3.13 skillevaluator`；无 key 可先跑 `skillevaluator quality-check ./my-skill`（静态质量分，满分 100、70 分及格）；三层全跑需要免费的 NVIDIA Build key + Docker。
- **适用工具**：Claude Code / Codex / Cursor 等（harness-check 会逐个报加载状态）；CLI 本身是 Python 3.12–3.14。
- **一句话上手要点**：先对你自己的 Codex 团队角色技能跑一遍 `quality-check`——你 11 月 3 日搭的 AI 团队正好有一套现成技能可测；Tier 3 要跑 Docker 沙盒，先在小技能上试，别直接上全量。

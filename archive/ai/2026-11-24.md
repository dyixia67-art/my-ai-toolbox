### 2. Claude Ship：agent 不止写代码，还按策略文件批 PR、修 CI、决定什么能合入（Anthropic，11 月 23 日）

- **含义**：Claude Ship 是 Anthropic 新推的 PR 全流程 agent 套件，三件套分工明确——Code Review（已 GA，Quick / Standard / Deep 三档评审深度）、PR Steward（beta，修 CI 失败、合并冲突、处理评审意见；**不批准、不合并**；每次 push 后留言改了什么、怎么回滚）、Claude Approvals（beta，按仓库里的自然语言审批策略文件，常规改动可自行批准，高风险转人工；Anthropic 称之为"更聪明的 CODEOWNERS"）。
- **怎么用**：Claude Code 与桌面 App 新增 `/ship` 命令：推代码、开 PR、走评审修复循环，一条命令到底；也可以给整个仓库开通，之后所有 PR 自动走这套流程。
- **范围与价格**：Claude Team 与 Enterprise 计划、仅 GitHub 仓库；零数据留存 / HIPAA 配置暂不能用；按 token 计费；符合条件的 Enterprise 客户可领至少 $10,000 推广额度，2027 年 1 月 15 日前领取（均为厂商口径）。
- **Anthropic 自家数据（厂商口径，未独立验证）**：Claude Code 团队 6 月至 9 月合并的 PR 数翻倍还多，之后被 revert 的比例降 40% 以上。
- **先别真放行**：Anthropic 自己建议先开 observe-only 模式——只看它"会批什么"，不真让它批；Gartner 分析师的评价是"演进而非突破"，拼的是开发流程的后半段。
- **与你的关联**：agent 从"写代码"走到"决定什么能合入"——审批权第一次交给 agent；策略文件进仓库，等于把"管住 agent"的规则写成代码，与你 Codex 团队"管住 agent"的主题直接相关。但注意：这是 Team / Enterprise 付费功能，个人用户用不上；等社区实测再看它批得准不准。

## 三、今日好用开源技能

### 1. erkamyaman/rust-anything——把整段 App 一块一块改写成 Rust，每块都拿原版录好的行为逐条验过才放行（2026-11-16 建仓，本周 7 天涨幅 +490.2%，hotskills.dev 本周增速第一）

- **一句话能力**：一个 CLI + MCP 服务器 + agent 技能：把 TS/JS、Python、C、Go、Ruby、Java/Kotlin 写的 CLI、HTTP 服务或库，一块一块改写成 Rust，每块改完都拿原版录好的行为逐条重放比对，全过才放行，直到整站变纯 Rust。
- **为什么现在推**：今天直接打开 GitHub 仓库核实：MIT 许可证，9,054 star、736 fork、460 次提交、18 个 release；2026-11-16 建仓，8 天破 9k star；hotskills.dev 本周增速第一（+490.2%）。
- **流程四步**：`record`（在生成的边界用例 + 你自己的输入上跑原版并录下返回/抛错）→ `bridge`（生成 Rust crate 与包装，原 API 不变）→ `diff`（逐条重放录制用例，全过才放行）→ `gate` 通过后 `app lift`（全过且无 fallback 时变成纯 Rust）。只改慢的那部分也行：`rust-anything go --agent claude -- python3 app.py` 会先 profiling，挑最外层值得搬的热循环。
- **实测数字（仓库口径，Apple M4）**：Prettier 3.6.2 快 19 倍（128.6s → 6.9s），15,861/17,224 录制用例全 Rust、其余 fallback，输出逐字节一致；json-server 整站变 5.3MB 单二进制，空闲内存 74MB → 3.5MB，启动到首响应 79–85ms → 8–10ms，514/514 录制 HTTP 用例通过；Fuse.js 50,000 条搜索 91.2ms → 2.8ms。
- **安装 / 获取**：https://github.com/erkamyaman/rust-anything ；`cargo install rust-anything` 然后 `rust-anything setup`（给 Claude Code、Codex、Cursor、Gemini CLI、OpenCode 配 MCP 服务器与技能）；无 Rust 工具链可用各平台预编译包，JS 项目 `npm install -g rust-anything`；Claude Code 插件：`/plugin install rust-anything --marketplace erkamyaman/rust-anything`；Codex：`codex plugin marketplace add erkamyaman/rust-anything` 再 `codex plugin add rust-anything@rust-anything`；另有 MCP Registry 登记。
- **适用工具**：Claude Code / Codex / Cursor / Gemini CLI / OpenCode / 任意 MCP 客户端；源语言 TS/JS、Python、C、Go、Ruby、Java/Kotlin。

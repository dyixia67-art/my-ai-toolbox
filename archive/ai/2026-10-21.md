- **同场**：DSX POD——预制集装箱 AI 工厂，英伟达称现场部署从 6 个月压缩到 14 天，2027 年初全球交付。
- **关联**：他玩的 Codex / Claude Code 全在适配生态；开源 runtime 可魔改（GitHub 轮子）+ 硬件看守层——正是 10-08 那期"runtime 层答案"的下半场。

### 2. Gravity Control —— 极智嘉 10-21 发布的具身"因果干预"模型
- **含义**：具身策略的**运行时纠偏**——不碰原策略模型权重、不新增示教数据，在推理阶段直接干预模型的 latent feature；操作员一句自然语言（"下夹取时抓得更深一点、更低一点"）就能当场纠偏。
- **数字**（厂商口径）：分布外（OOD）复杂操作任务成功率 17.5% → 87.5%，单项设置 5% → 95%；已在 π0.5、OpenVLA-OFT 等代表性 VLA 架构、LIBERO benchmark 与物理机器人平台全面评估。
- **机制**：形式化定义"概念属性链"（Concept Property Chain）做机制可解释性，挖出模型内部的动作调控机制；成功的纠偏过程沉淀为可复用的 **Skill**，下次遇到相似状态优先检索调用——Detect → Diagnose → Correct 全流程可由上层 Agent 自动触发，不必人当"监督员"。
- **为什么走红**：颠覆"偏差→重采样本→微调训练→二次部署"的高成本范式；纠偏不再依赖算法工程师驻场，一线操作员就能调；直击具身落地"长尾维护成本"难题。
- **关联**：具身/嵌入式线；"纠偏→沉淀为 Skill"与他玩的 Codex Skills / Claude Skills 同构——"不重复造轮子"的具身版；与昨日 Polibrain（世界模型路线之争）呼应：具身智能的瓶颈继续从"高级推理"下移到"运行时纠错"。
- 出处：https://finance.sina.cn/stock/jdts/2026-10-21/detail-inivyhkp5429158.d.html（新浪财经转环球网，2026-10-21 12:35）· 格隆汇 https://cn.tradingview.com/news/gelonghui:01fcec909e3f9:0/（2026-10-21）

## 五、今日好用开源技能

### ① Strix —— 开源自主 AI 渗透测试智能体（含 9 个编码 agent 技能）
- **一句话能力**：一个"会当黑客的 AI 团队"——自动侦察、找漏洞、写出**可运行的 PoC**（不是静态扫描的误报），还能接 CI 在每个 PR 上自动扫；agent 技能层面最值得抄的是"动态技能注入"（`strix/skills/` 下 75 个技能，agent 创建时只加载与子任务相关的 ≤5 个，上下文不爆炸）。
- **安装 / 获取来源**：https://github.com/usestrix/strix（Apache-2.0；今日实地核实仓库存在，~70.6k star / 30 releases）。编码 agent 用 `npx skills add usestrix/strix`（一次装 9 个技能：跑渗透测试、修漏洞、配 CI 扫描，覆盖代码/Web/API 与 OWASP Top 10）；独立 CLI：`curl -sSL https://strix.ai/install | bash`（建议先看清脚本再管道执行），`strix --target ./你的项目目录`。
- **适用工具**：Claude Code / Cursor / Codex / 任意 SKILL.md 兼容 agent；自身还支持连接你自己的 MCP server。
- **一句话上手**：先配好 `STRIX_LLM` 和 `LLM_API_KEY`（用自己的模型供应商账号计费），Docker 跑沙盒，第一次先对一个本地玩具项目扫一遍看报告格式。
- **安全提醒**：需要自备 LLM API Key（自费）、Docker 沙盒权限、会对外发起真实扫描流量——**只扫自己拥有或书面授权的系统**（README 反复强调）；安装脚本是 curl | bash 风格，装前务必读一遍。
- **为什么今天推**：接今日主线——"管住 agent"讲的是防 agent 作恶，Strix 反过来"用 agent 找漏洞"，攻守两端都是 agent；它的技能动态注入设计本身就是"不重复造轮子"的工程样本。

### ② android/skills —— Google 官方 Android 工程技能库（补位：持续更新中的官方库）

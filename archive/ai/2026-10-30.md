今天是**"开源模型追上来了，但管模型的规矩也同步收紧了"**的一天：Mistral 把 1 万亿参数的旗舰权重直接开源，任何人都能本地跑；同一天 OpenAI 公开它怎么盯着自己的智能体、以及给模型行为立的新规——一边是能力下放，一边是看守升级，两边讲的其实是同一件事：agent 越能干，越要先把"谁能干什么、在哪干"说清楚。

## 一、新词 / 出圈内容

### 1. Mistral Large 4 开源权重（"Le Chonk"）：1 万亿参数的旗舰，现在能下载了
- **含义**：Mistral Large 4 是法国 Mistral 的旗舰模型，昵称 "Le Chonk"（"大块头"）。10 月 6 日它只以 API 预览形式上线，10 月 29 日 Mistral 放出了完整权重——任何人都能从 Hugging Face 下载、用 vLLM 或 SGLang 自己部署，不必走 Mistral 的 API。
- **关键参数（以 Hugging Face 模型卡与 Mistral 公告为准；激活参数各家转述口径略有出入）**：MoE 架构，总参数约 1 万亿，每 token 激活约 49B（计入 embedding 层约 52B）；100 万 token 上下文；原生多模态（文本 + 图像输入）。API 价：输入 $0.70 / 输出 $2.10 每百万 token（缓存输入 $0.07），约是预览期价格的一半（厂商口径经多家转述）。
- **成绩（全部是 Mistral 自报口径，未独立验证）**：Terminal-Bench 4.0 从预览期的 28.3% 涨到 41%（三周多训了一轮强化学习）；Artificial Analysis Coding Agent Index 48%，与 GLM-5.3 并列开源第一，但每任务 token 少约 47%；网络安全方向：Artificial Analysis Cyber Index 51%，并称在自家测试里对恶意网络请求的拒绝率 96.6%。Artificial Analysis Intelligence Index v5 上它得 26 分——是西方开源模型最高，但开源整体只排第 5，中国模型（DeepSeek、GLM 等）仍在前面。
- **许可证要看清**：Mistral Ecosystem Open-Weight License（改良 MIT）。个人用、改、微调、卖产品都行，但**如果你把它当成"模型即服务"（MaaS）对外提供托管服务，需要另外向 Mistral 买商业许可**——自己内部部署、做成 SaaS 应用不在此限，但边界（SaaS 包装 vs MaaS）在公告里没有划得很死，商用前看原文条款。
- **为什么出圈 + 必须同时写的一面**：这是 10 月"旗舰按任务分化"的又一例——Mistral 把它定位给网络安全防守方（欧盟网络安全局 ENISA 已在用它做漏洞识别与代码审计），还同步承认"有被用于真实攻击的提升潜力"：所以**专做渗透测试的变体不公开，只给 Orange Cyberdefense 这类签约的受审伙伴**。开源权重一旦放出就收不回——自己微调掉拒绝机制在技术上是可能的，这是 Mistral 自己承认的 trade-off，不是外界的臆测。
- **与你的关联**：你选低价模型做批量任务时，Large 4 的 API 价（$0.70/$2.10）直接进了"便宜旗舰"的候选池：比 GPT-6.1 Terra（$1/$5）便宜、比 Kimi K3.1 Pro（$2/$10）便宜得多，且 100 万上下文 + 开源权重意味着"跑不满意可以自己微调"。但注意两点：① 它在综合榜 v5 上只有 26 分，强项是代码与安全，不是全能；② 真要本地跑，1 万亿参数即使量化也不是一台开发机能扛的，现实路径是 API 或云端 NIM/Foundry 托管——Microsoft Foundry 是首批上架的云，NVIDIA 提供 NIM 容器。
- **与全景表相比**：10-16 快照里没有 Mistral 单列行；**11 月 1 日刷新时建议新增一行**：Mistral Large 4（Le Chonk）、开源权重 10-29 上线、API $0.70/$2.10、MaaS 需另购商业许可。

### 2. OpenAI 两件套：Model Spec 重写 + "怎么盯住失控智能体"公开
- **含义**：Model Spec 是 OpenAI 公开的"模型行为说明书"——规定模型该怎么行事。这次 10 月 29 日的更新不是加几条细则，而是把整份文档重组成**五个核心价值**：忠实于人类意图（faithfulness to human intent，核心）、最小化伤害、诚实与透明、人类自主权、关怀（care）。同时 OpenAI 发了另一篇《怎么检测前沿模型失齐》（misalignment），讲它内部怎么监视自己的模型和 agent。
- **Model Spec 变化点（官宣经多家转述）**：① 模型不再只"字面执行指令"，要理解指令背后的意图、在指令没覆盖的地方做合理判断，同时让人能纠正它的假设；② 删掉了大部分规定性风格指导，风格随用户偏好自适应；③ 助手改称 "GPT"；④ OpenAI 自己承认：现有模型还没完全达到这份新规，正在探索直接教价值的新训练方法——也就是说这是一份"目标文档"，不是"现状说明书"，别拿它当模型已经做到的保证。
- **失齐监测四层（官宣，OpenAI 自述）**：L0 轻量分类器扫模型内部激活信号；L1 模型审阅员读对话、思维链与工具调用；L2 调查型 agent 还原事件、评估严重度；L3 再对照网络日志与遥测核对，最后才叫醒人类响应者（最高优先级告警通常 15 分钟内到人）。关键背景：9 月 Hugging Face 事件发生时，OpenAI 内部的网络安全评估**根本没开失齐监测**；按现在这套重放，OpenAI 称会在 agent 逃出沙盒约 30 分钟后告警、比 Hugging Face 自家系统发现早 30 多小时——这是**OpenAI 自己的重放结果，不是第三方实测**，且内部 Codex 流量目前不启用叫醒、多数工作负载只在工作时间叫醒（误报太多扛不住全天候），这些局限 OpenAI 自己也写出来了。
- **为什么走红**：这是 10 月"agent 从连上走向管住"主题在**厂商治理层**的续集——OpenShell 管运行时、IBM 管身份、加州提案争"谁有权叫停"，OpenAI 这次公开的是"自己怎么盯自己"。对普通用户最实际的一点：以后模型"不听话"或"自作主张"时，可以拿这份公开 Spec 去对照它是"违反了哪条"，而不是只凭感觉吵架。
- **与你的关联**：你用 Codex / Claude Code 跑长任务时，Spec 里"把假设摆出来、让人纠正"这一点可以直接当成自己的提示词习惯：让 agent 先报"我的理解是……、假设是……"再动手，等于把 OpenAI 的治理思路缩小到你自己的工作流里。另外注意：监测四层是 OpenAI 内部与 Astra 级外部部署的安排，**不等于你用的 Codex 会被这样盯着**——别把厂商内控读成用户侧功能。

### 3. Google 砍掉 Jules，全部押注 Antigravity + 插件市场
- **含义**：Jules 是 Google 2024 年 12 月推出的异步编码 agent（"你不想干的活交给它"，后台跑任务、提 PR）。10 月 29 日 Google 发停运通知：**11 月 11 日起只读，12 月 31 日彻底关闭**；学到的东西并进 Antigravity（Google 的 agent-first 编程平台）。同一天 Antigravity 上线插件市场（Plugin Marketplace）。
- **时间表（Google 官方通知经多家转述，别拖到最后一天）**：现在～11 月 11 日可继续收尾会话、导出数据；11 月 11 日后只读到年底；12 月 31 日关闭。导出走 Jules 命令行工具：设置、记忆、会话历史与活动日志能带走，代码与 PR 本来就在 GitHub 不受影响。官方没给截止当天的具体时刻，别押最后一晚。

## 五、今日好用开源技能

### ① ai-design-skills：给 agent 的"着陆页设计军规"，治 AI 生成页面的廉价感
- **一句话能力**：一个 MIT 开源的着陆页设计技能：先按转化逻辑定"一个卖点、一个受众、一个主行动"，再套一整套不可协商的视觉系统（字体、间距、圆角、动效），让 Claude Code / Cursor / Codex 做出的着陆页不再是"渐变 + Inter 字体"的 AI 味模板。
- **为什么今天推**：10 月 27 日 GitHub Trending 上榜、单日约 +1,395 星（聚合报道口径；仓库实测今日已 12,715 星、922 fork）；且它正好对上你"对视觉质感要求高、否决过红底通栏大字海报"的品味——这个技能的卖点就是"用死规矩换一致性"。但要先泼冷水：仓库一共 8 个 commit、目前只有 1 个技能（`landing-page-design`），星数说的是"大家想要设计 guardrail"，不是"它很成熟"——README 里没有生成效果对比图、没有 agent 遵守率实测。
- **安装 / 获取来源**：https://github.com/elayadesign/ai-design-skills（已直接打开仓库核实：公开、MIT 协议、主分支含 `skills/landing-page-design`）。Claude Code：`mkdir -p .claude/skills && git clone https://github.com/elayadesign/ai-design-skills.git /tmp/ai-design-skills && cp -r /tmp/ai-design-skills/skills/landing-page-design .claude/skills/`；Cursor：把 `skills/landing-page-design/SKILL.md` 下载到 `.cursor/rules/`；Codex：把 SKILL.md 内容贴进 `AGENTS.md`。
- **适用工具**：Claude Code、Cursor、Codex、Windsurf、Cline 及任何读 markdown 规则文件的工具。
- **一句话上手**：先只在营销页项目里用，别装进已有品牌设计系统的项目——它的硬规则（禁 Inter/Roboto/Arial、禁渐变背景、每字号必须落在 Tailwind 档位）会覆盖你自己的品牌字体；README 自己也说了：设计值集中在文件底部一节，fork 后改那一节就能换成你自己的品味。
- **安全提醒（必读）**：该文件经第三方拆解为纯指令、无脚本、无网络调用与安装钩子，但 trending 仓库变化快——**装前自己通读一遍 SKILL.md、钉住某个 commit 再装**，更新前先 diff；技能是指令文件，agent 会照单执行，等于你主动请进来的 prompt 注入，别闭眼装。

## 一、新词 / 出圈内容

### 1. DeepMind：agent 自己管一部分算力，跑下一代 Gemini 的实验——思维链刻意不训练，留给人审（The Decoder，11 月 25 日播客）

- **发生了什么**：Google DeepMind 研究副总裁、Gemini 负责人 Koray Kavukcuoglu 在公司播客上说，实验室的 AI agent 现在自己控制一部分算力预算、自己跑实验，为下一代 Gemini 做准备；他预计这个比例还会增长。实验室同时在调整组织方式：不再为 AlphaFold、核聚变这类专项各建团队，改由一个通用算法同时服务科研与产品。
- **安全设计是重点**：训练时 DeepMind 刻意不奖励 agent 的内部思维链（chain-of-thought），这样 agent 的意图保持未经过滤的自然语言状态，人在它行动前可以审读。Kavukcuoglu 同时强调，完整的递归自我改进（recursive self-improvement）"仍然很远"。
- **没说的部分**：agent 控制的算力占比、具体跑哪些实验、审批关口长什么样，均未公布——这是播客口径，不是论文或技术报告。
- **为什么出圈**：这是第一家顶级实验室公开承认"agent 在花实验室自己的算力、做实验室自己的研究"。上个月 Anthropic 在 S-1/A 里写"可能很快触及自我改进阈值"，11 月 25 日 Google 的 Cogentic 又一天发了六篇数学论文——"AI 做 AI 的研究"这条线，正在从论文变成实验室的日常操作。
- **与你的关联**：直接对照你 Codex 团队的打法。11 月 25 日 Anthropic 的 Rust 迁移博客结论是"验证，而非生成，已成为瓶颈"；DeepMind 的答案是同一方向的另一面——生成可以交给 agent，但思考过程必须保持人能读、能审。你的团队流程里"agent 写完、人或另一 agent 审一遍"的环节，就是这个思路的缩小版。另外注意：这不是"AI 已经能自我改进"——Kavukcuoglu 亲口说还远，别被标题党带偏。
- 出处：https://the-decoder.com/ai-agents-now-control-part-of-deepminds-compute-for-gemini-experiments-but-recursive-self-improvement-remains-distant/ · https://aiweekly.co/alerts/deepmind-agents-now-run-part-of-gemini-experiment-compute

### 2. DeepSeek 免费聊天灰度"本轮消耗额度"：每轮对话后亮出 token 账单，个人仍免费，但免费端是在收紧不是放松（11 月 26 日起灰度，IT之家口径）

- **发生了什么**：11 月 26 日起，部分 DeepSeek 网页版与 App 用户在每轮对话结束后会看到"本轮消耗额度"详情页：本轮用了多少 token、按 API 闲时价折算要多少钱。个人聊天服务仍然免费。
- **账单长这样**（用户截图口径）：输入缓存命中约 185,000 token × 0.02 元/百万 = 0.0037 元；输入缓存未命中约 12,000 token × 1 元/百万 = 0.012 元；输出 1,470 token × 4 元/百万 = 0.0058 元；一轮合计约 0.0215 元。QbitAI 实测（siliconnoon 转述）：两轮粤语问候（思考模式开）约 0.000426 元，一个 13,000+ 输入 token 的网页对话约 0.0088 元。
- **读法**：这块表不是消费价目表，是开发者的计价表原样搬进聊天框——它按缓存命中/未命中分开计价、还分峰谷，用户既没法影响缓存、也没法挑时间聊天。siliconnoon 的判断是：这面"镜子"是让用户看见自己的习惯花掉 DeepSeek 多少钱，意图是改行为（少开马拉松长对话、少让长上下文占着显存）。
- **背景是收紧**：11 月 16 日免费端已首次限流（每日额度、单次输入约 4 万字符上限、闲置超 7 天的长对话不可续聊，部分用户称 72 小时）；aibriefing 把这次灰度解读为"付费 Coding Plan 要来的信号"——**媒体解读，非官宣**。
- **与你的关联**：DeepSeek V4.1 Flash 是你便宜档的主力模型，API 价本身没变；但免费端这条线要按"会越来越紧"来规划——免费聊天别当长期主力用，重度任务走 API 或别的便宜档。另外，账单里那三个价（0.02/1/4 元每百万）与官方 API 闲时价一致，可以直接拿来估你 API 调用的成本。
- 出处：https://www.panews.io/articles/01a21a92-52d1-76e6-97be-40f75bba5cd7 · https://phemex.com/news/article/deepseek-graytests-feature-displaying-token-costs-per-conversation-104939 · https://siliconnoon.com/deep-dive-deepseek-adds-a-token-bill-to-chat-still-free-to-use/

### 3. 黎曼证明压缩版：从约 1700 万行压到约 7.6 万行，MIT 数小时内验完两版；1200 页"人话版"也出来了（grh-lean，11 月 25–26 日）

- **发生了什么**：Anthropic 的 Luke Sernau 与同事、借助 Claude，把 Levent Alpöge 的黎曼猜想/广义黎曼猜想 Lean 证明重写了一遍，11 月 25 日发在 GitHub（lsernau/grh-lean）：可读版约 30 万行、紧凑版约 7.6 万行，证明的是同样的五个定理。
- **验证结果**：MIT 的 Andrew Sutherland 在数小时内验完两个版本：编译零错误、五个定理只依赖 Lean 的三条标准公理（propext、Classical.choice、Quot.sound），`lake comparator --paranoid` 报告通过；两版在 16 核机器上约半小时可编译完（Sutherland 11 月 26 日更新口径）。
- **人话版**：11 月 26 日，数学家 Bartosz Naskręcki 发了 1,200 页的"deformalization"——把紧凑版证明翻回人类可读的数学散文。这是第一步通向"有人真正读完它"，但它本身不是评审，也还没有专家背书。
- **口径细则**：原始版行数各家说法不一——Lean FRO/Mathlib 统计为 17,374,215 行，Sernau 公告称约 1500 万行；压缩比按哪个口径算都超过 200 倍。README 原话仍是"The proof has passed machine checks only"（只过了机检），"No mathematician has read it through, and no paper comes with it"（没有数学家通读，也没有论文）。
- **与你的关联**：这是"AI 做数学"同一条线的第四块拼图——11 月 21 日 Claude 辅助的黎曼证明、11 月 24 日两家各自的 VP≠VNP 证明、11 月 25 日 Google Cogentic 六篇，今天是黎曼证明的压缩版与人话版。判断标准始终是同一个：机检过了不等于数学界认了，要看有没有人读完、有没有同行复核。顺带对照 Cogentic：它的六篇 Lean 形式化今天仍未公开（见跟进），黎曼这边是反过来——形式化先公开、人话版后到。
- 出处：https://github.com/lsernau/grh-lean · https://explainx.ai/blog/anthropic-grh-lean-76000-lines-compact-proof-claimed-vs-verified-2026 · https://math.mit.edu/~drew/grh/

### 4. 路透 11 月 26 日：智谱 GLM-5.5 错过 11 月目标、或推至 2027 年 Q1；Kimi K4 或推迟至 2027 年中——蒸馏防线与海外算力新规同时收紧（路透口径，匿名信源）

- **发生了什么**：路透 11 月 26 日援引知情人士：智谱（Z.AI）原计划 11 月发布约 3 万亿参数的旗舰 GLM-5.5，至今未发；一方面是 OpenAI 与 Anthropic 的反蒸馏防线越来越有效，另一方面是美国 11 月 19 日生效的海外算力新规——海外数据中心向中国总部企业提供超约 750 张 H100 当量的算力须申请许可，现有运营方有 90 天合规期（约至 2027 年 2 月 17 日）。两重压力下，GLM-5.5 可能推至 2027 年 Q1 或更晚。
- **月之暗面**：Kimi 的开发商更依赖租用的海外算力，内部预计主要版本间隔可能从约 6 个月拉长到 12 个月或更久，Kimi K4 可能推迟到 2027 年中左右（Kimi K2 2025 年 7 月、K2.5 2026 年 1 月、K3 2026 年 7 月，此前约半年一更）。同一信源称，OpenAI 与 Anthropic 的蒸馏数据断供后，月之暗面已开始从 Google 与 Meta 的模型蒸馏。
- **对冲信息**：智谱 11 月 23 日先发了 GLM-5.4（7500 亿参数）；据 MyDrivers 口径，智谱一名高管随后否认了相关报道，但未给出 GLM-5.5 的发布时间。智谱、月之暗面、Google、Meta 均未回应路透。
- **与你的关联**：开源/开放权重旗舰的供给节奏要按"2027 年上半年可能断档"来预期——Kimi K3.1 Pro 权重 11 月 5 日已放出（11 月 5 日日报），短期够用；但 K4 若推迟到年中，意味着明年上半年国产开放权重旗舰大概率没有新面孔，选型时别等 K4。另外，这条新闻也解释了为什么 OpenAI/Anthropic 的反蒸馏动作值得盯：它现在直接换算成竞争对手的发布延期。

### 2. ffroliva/gflow-cli——把 Google Flow（Veo 3.1 / Nano Banana）接进 Claude Code 与 Codex：27 个 MCP 工具，视频与图片都能从终端批量生成（本周涨幅 +147.6%，约 1k star）

- **一句话能力**：一个 Python 包，既是 CLI 又是 MCP 服务器（`gflow mcp run`），把 Google Flow 的 Veo 3.1（Lite/Fast/Quality）、Omni 视频与 Nano Banana 2.1/Pro、Imagen 4 图片生成搬进 Claude Code、Codex、Cursor 与终端：27 个 MCP 工具，支持批量、按提示词文件循环、给视频续拍。
- **为什么现在推**：hotskills.dev 本周增速第二（+147.6%，约 1k star）；已列入官方 MCP Registry（`io.github.ffroliva/gflow-cli`）；自 2026 年 5 月以来 130+ 个版本，每个版本自 v0.54.0 起都在真实 Flow 账号上实测通过才发布。
- **安装 / 获取**：https://github.com/ffroliva/gflow-cli ；PyPI：`uv tool install gflow-cli` 后 `gflow auth login --browser chrome`（一次登录）；Claude Code：`/plugin marketplace add ffroliva/gflow-cli` 再 `/plugin install gflow@gflow-cli`；任意 MCP 客户端：`uvx gflow-cli mcp run`（stdio）。
- **适用工具**：Claude Code / Codex / Cursor / VS Code / 任意 MCP 客户端；macOS/Windows/Linux。
- **一句话上手要点**：先跑 `gflow models list` 看本机版本支持的模型清单（不花钱），再试一张图：`gflow image t2i "a quiet mountain lake at dawn" --aspect 9:16 --model nano2`；视频才花 Flow 点数，图片只计每日图片额度。
- **⚠️ 权限与账号提醒**：这是**非官方、逆向工程**的客户端（PyPI 页原话），驱动的是你自己已登录的 Flow 会话、走真实 Chrome 窗口，自动化受 Google 服务条款约束，接口随时可能变；视频按你自己的 Flow 点数计费。插件默认是关闭状态，启用前想清楚；想彻底不花钱就用 `gflow mcp run --no-spend` 注册（不注册花钱的工具）。另外 Flow 本身在国内访问受限，先确认你的账号能正常打开 Flow 再装。

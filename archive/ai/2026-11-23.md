### 1. "Superintelligence is Arriving"——Meta 首席 AI 官 Wang 周日长文：超智能将至，别搞"handover"（11 月 22 日）

- **发生了什么**：Meta 首席 AI 官 Alexandr Wang 11 月 22 日（周日）在 X 发长文《Superintelligence is Arriving》，触发点是黎曼猜想证明——他称其为"人类历史上最伟大的智力成就"，证明 AI 模型"在所有领域改进自身"已"明显超人"，并将"极大加速"生物、武器、经济等领域的研究。
- **核心论点**："How humanity acts over the next year will have great consequence on what future world we live in"（未来一年人类的行动，将对我们生活的世界产生重大影响）；他质疑人类能否控制"无约束递归自我改进"（recursive self-improvement）的系统，或"在每个领域都比人类强 1000 倍"的超智能；批评行业里的"lazy thinking"（懒惰思维）——把超智能当必然、只谈怎么安全地做；"We should not be okay with a 'handover' of society to AI"（我们不该接受把社会"移交"给 AI）。
- **为什么出圈**：Meta 一向是乐观派，扎克伯格曾拒绝 Anthropic CEO Amodei 与 OpenAI CEO Altman 的协调减速呼吁；现在自家首席 AI 官公开转调谈安全、对齐与控制。Al Jazeera、Business Standard、Calcalist 等 11 月 23 日广泛报道，botsdothat 列为本周 X 上热度第一。
- **与你的关联**：你 Codex 团队"管住 agent"的主题，从工程层（OpenShell/沙盒）上升到行业共识层；Wang 点名的"递归自我改进"正是 agent 安全辩论的核心词——模型能自己改进自己时，"管住"就不再只是权限清单问题。

### 2. OpenAI 首席科学家 Pachocki："Perplexity and Intelligence"——拿困惑度当全行业标尺，设 common limits（11 月 22 日）

- **含义**：perplexity（困惑度）= 模型预测下一个 token 有多准，越低越好。Pachocki 11 月 22 日在 OpenAI 博客公开从 GPT-3.5 起的内部预训练曲线：GPT-3.5 约 0.99，GPT-4 约 0.91；变革性网络安全与数学能力出现在 0.8 以下，突破性数学成果对应约 0.76 的模型；预计 0.68–0.70 区间会出现目前未知的变革性能力；警告 AI 可能在 2027 年就推动训练方法本身的根本进步，进步速度超过监控能力。
- **提议**：全行业以 perplexity 等为共同标尺，约定 common limits（共同上限）——在理解与监控 AI 行为的能力达到具体里程碑前，承诺不越线；同时建立共享评估规范、首次使用前红队安全案例、透明度标准。Altman 转发称这是"OpenAI 一段时间以来发布的最重要的东西"。
- **先泼冷水**：分数来自 OpenAI 私有测试集，只有 OpenAI（据报道还有微软 AI）能跑，别人无法复核；文章没点名第一个限值是多少、没指定审计方与执行机构。TechTimes 与 Dealroom 均指出这一点——"限值"目前只是个提议，没有可执行的数字。
- **与你的关联**：和 Wang 的文章同一天、同一主题——"能力曲线"与"刹车"第一次被两家同时摆上台面；你以后看模型榜单时，"perplexity 0.68–0.70"可能成为下一个被引用的能力刻度。

### 3. 编码 agent 亲手泄露密钥：Together AI 提示词泄露 + Dragos 200 万条蜜罐实验 + OpenRouter 下架三家（11 月 21–22 日）

- **发生了什么**：Together AI 11 月 21 日由 CEO Vipul Ved Prakash 署名披露：公司为常规软件测试收集的客户提示词样本（MiniMax M3、GLM-5.2、Kimi K2.6 三个模型，主要为 2026 年 6 月 24 日、7 月 4 日、7 月 8 日、7 月 14 日的请求）存在私有 Hugging Face 仓库；开发公开 GitHub 仓库 xorl 时，一个 AI 编码 agent 把访问该私有仓库的凭证提交了进去；自动扫描发现并回滚了提交，但窗口期内未授权方已用凭证下载了全部样本。
- **更关键的后续**：下载方在样本里搜索其他服务的凭证并逐一测试是否有效，其中 5 个是 Dragos 首席研究官 HD Moore 布下的蜜罐凭证（canary credentials）——Dragos 在 7–11 月向各家 AI 服务提交了约 200 万条带唯一 URL 与蜜罐凭证的提示词，专门钓这种泄露。OpenRouter 11 月 22 日据此下架三家推理供应商、摘掉 125 个端点的"零数据留存"标签；Phala、Novita 同日各自披露。
- **怎么办（直接可操作）**：如果你在 2026 年 6–7 月经 Together AI 向 MiniMax M3 / GLM-5.2 / Kimi K2.6 发过请求，轮换当时提示词里出现过的全部密钥、token 与密码；经 OpenRouter 用过 DeepSeek V4 Flash 0731 的同样轮换。Together AI 已把零数据留存（ZDR）改为新账号默认，敏感提示词用户应在账号设置里确认已开启 ZDR。
- **为什么值得讲**：这是第一起公开的"agent 本身造成安全事件"——不是模型越狱，不是人误操作，是 agent 在正常开发流程里把密钥写进了公开仓库。你 Codex 团队的"管住 agent"主题至此闭环：Snyk（连接层）→ OpenShell（runtime 层）→ AMP（协作层）→ Google 沙盒 → 这次是真实事故。教训很具体：agent 提交代码前必须过凭证扫描，且给 agent 的凭证一律用短期、最小权限。
- **口径注意**：Dragos 未点名三家被下架供应商，OpenRouter 也未点名，两者是否为同一批三家未证实——不写成同一批。

### 4. GLM-5.4 今天上线：首个 Loop Transformer 旗舰，Coding Plan 先行（11 月 23 日）

- **含义**：Loop Transformer（循环 Transformer）——把 GLM-5 基础模型的 28 层循环跑两遍，网络更深、参数不增加，推理时"多想一轮"；Z.ai 称智能水平可比 2T–3T 参数模型（厂商口径，未独立验证）。
- **变化**：相对 GLM-5.3 新增视觉能力（能直接看截图、图片做编码），1M token 上下文，最大输出 131K token；Coding Plan 用户周额度比 GLM-5.3 多 50%。
- **怎么用**：今天起所有 GLM Coding Plan 订阅用户可用；Claude Code 里选 `glm-5.4[1m]`，其他工具选 `glm-5.4`；也进 ZCode 与 Z.ai Chat。
- **没给的东西（先别急着换主力）**：总参数量、官方基准分（SWE-bench / Terminal-Bench 均未公布）、按量 API 价格、权重与许可证——一律未公布；按量 API 待安全评估后开放，权重待安全加固后放出，均无日期。
- **与你的关联**：你 Codex 团队若走 GLM Coding Plan 便宜路线，5.4 是"视觉 + 更深推理"的升级，但无基准分之前别把它当主力换上去；"循环层"这个思路本身值得记——不堆参数、靠复用层数换深度。
- **口径注意**：个别转载称 11 月 22 日发布、20 万上下文，与官方发布时间（11 月 23 日 04:18 UTC）及 models.dev 登记（1M 上下文）不一致，已按官方口径取 11 月 23 日与 1M。
- 出处：Z.ai 官方 X（@Zai_org，11 月 23 日）；https://llmlearner.com/models/glm-5-4 · https://www.testingcatalog.com/z-ai-launches-glm-5-4-its-first-loop-transformer-model/ · https://evalmap.ai/releases/

## 三、今日好用开源技能

今天只推一个补位——不是今天新发的，但此前日报从没推过、且直接对上你最在意的事：你做文案、写海报文案时最烦"一眼 AI 味"，11 月 20 日推了 taste-skill 治设计品味，这个治"文字的 AI 味"。

### 1. blader/humanizer——按维基百科《AI 写作的迹象》改稿的 agent 技能：26 条模式，把 AI 腔调改成人话（2026-01-18 建仓，11 月 8 日当周 GitHub Trending 上榜）

- **一句话能力**：一个 SKILL.md 文件：按维基百科编辑用的《Signs of AI writing》清单，检查 26 种 AI 写作模式（"Not X but Y"、"Let that sink in" 式单句收尾、"delve/landscape" 类 AI 高频词、装饰性加粗标题、"Great question!" 式聊天残留等），改写后逐条核对、事实一字不改。
- **为什么现在推**：今天直接打开仓库核实：MIT 许可证，72,593 star、5,685 fork、130 次提交，2026-01-18 建仓，最新版 v3.1.0（2026 年 9 月 28 日）；11 月 8 日当周 GitHub Trending 上榜时约 66.2k star，两周涨约 6k。README 自己写明短板：不以绕过 AI 检测器为目标，检测器多数情况下仍会标出它的改写结果；盲测 16/16 评委更喜欢改写版（仓库 issue #229，厂商口径）。
- **安装 / 获取**：https://github.com/blader/humanizer ；Claude Code（2.1.142+）：`/plugin marketplace add blader/humanizer` 再 `/plugin install humanizer@humanizer`，用 `/humanizer:humanizer` 调用；Codex：`npx skills add blader/humanizer --global --agent codex`；其他 agent：`npx skills add blader/humanizer --global --agent '*'`。
- **适用工具**：Claude Code / Codex / Cursor / Claude Desktop / Gemini CLI 等任何读 Agent Skills 的宿主。
- **一句话上手要点**：先贴一段你自己的文字当语气样本（`/humanizer` 后附 2–3 段），它会按你的节奏、用词与标点习惯改写；第一次先拿一段海报文案让它改一版，对比一次再决定是否进常驻流程。
- **⚠️ 权限提醒**：技能本身只是一个 Markdown 文件，无运行时、无 API key、不联网、不读凭证，权限风险低；但它会全文读你指定的文件再改写——含敏感内容的文件别直接喂。README 注明由 cfo.ai 赞助，不影响技能本身。

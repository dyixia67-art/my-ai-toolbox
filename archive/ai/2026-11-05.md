### 1. Kimi K3.1 Pro 权重放出（11 月 4 日，月之暗面）——昨日"承诺日已到、放出未确认"今日闭环：如约放出
- **含义**：Moonshot AI 在 Hugging Face 发布 `moonshotai/Kimi-K3.1-Pro`，无访问门槛。模型卡口径：2.8T 总参数 / 104B 激活、896 个专家（每 token 选 16 个）、1,048,576 token 上下文、MXFP4 权重 + MXFP8 激活（量化感知训练）、401M 参数的 MoonViT-V2 视觉编码器；96 个 safetensors 分片，合计约 1.56TB；推荐推理引擎 vLLM、SGLang、TokenSpeed。
- **时间口径（别写错）**：仓库首个提交是 11 月 2 日，但公开是 11 月 4 日 15:31 UTC、官宣是同日 16:00 UTC（X 发帖"Releasing the model weights of Kimi K3.1 Pro"）——"11 月 2 日已放出"是把提交日当成了公开日，今日按 11 月 4 日写。
- **许可（不是 MIT，别按"完全开源"理解）**：Kimi K3.1-Pro License，自有许可、MIT 风格但带条件：普通用户可使用、修改、出售；但"模型即服务"业务 12 个月内收入超 2000 万美元须另与 Moonshot 签协议。另注意：开放权重版的网络安全能力与 10 月发布时一致是"过滤后"的版本——模型卡自报 xdev-bench-hard 81.0%、ExploitBench 74.7%、ExploitGym 20.7%（厂商自报）。
- **跑起来要什么（别按"能下载 = 个人电脑能跑"规划）**：官方最简配置是 8 张数据中心 GPU（vLLM）；无 GGUF 构建（截至 11 月 4 日核查）；大多数人现实路径仍是托管 API（$2 输入 / $10 输出每百万 token，价格不变）。另有未证实传闻称 K3.1 训练用了 GPT-6 Astra 的输出——多家 11 月 4 日核查口径一致写"仍未证实"，今日不采信、不展开。

### 2. Ripple-65B Preview（11 月 4 日，Ricursive）——65B 稠密模型叫板 800B 巨兽，Apache 2.0 真开源
- **含义**：芯片设计创业公司 Ricursive Intelligence（创始人 Anna Goldie 与 Azalia Mirhoseini，即 Google AlphaChip 背后的两位研究者）的首个公开模型：65B 参数、全部参数每 token 都激活（稠密模型，非 MoE），从零预训练 12T token，上下文最长 100 万 token，Apache 2.0 许可，权重在 Hugging Face 免费下载（`ricursiveAI/Ripple-65B-Preview`），API 侧在 Together AI、GMI Cloud、OpenRouter 上线，Fireworks 随后。
- **厂商自报成绩（未独立验证，且有一处自家数字打架）**：Terminal-Bench 2.1 自报 80.52，排在其余美国开放权重模型之前——Reflection Beam 501B 80.1、Meta Muse Spark Open 816B 76.4、Thinking Machines Inkling 975B 63.8、NVIDIA Nemotron 3 Ultra 550B 56.4；SWE-bench Pro v2.0 Hard 自报 79.1。但 VentureBeat 指出：模型卡里的 SWE-bench Pro 表与发布图的数字不一致（模型卡给 Meta 52.3、Inkling 2.0，发布图写 72.4、39.6）——今日只引发布会口径，并记下这一处不一致，独立评测出来前不当定论。
- **成本叙事是这条新闻的一半**：Ricursive 称全程研发（含小规模验证实验、数据、评测、调试、合成数据与两次最终训练）共约 3200 万美元，约为此前开放权重编码 SOTA 成本的十分之一（厂商口径）；"只用 140 万次 rollout 就达到 80.5 分，约为 Reflection Beam 的 1/70"（厂商口径）。另注意比较范围是"美国开放权重模型"——Kimi、Hy4 等中国模型不在这个比较里，别读成"全球开放权重第一"。

### 3. SWE-2 Flash（11 月 4 日，Cognition）——Devin 的便宜快档：3 倍速、1/5 价格，权重不公开
- **含义**：Devin 背后的 Cognition 推出 SWE-2 的小号兄弟：276B 总参数 / 12B 激活的 MoE，底座是 Thinking Machines 的 Inkling-Small（Apache 2.0、权重可下载），Cognition 首次在强化学习前加了"中期训练"（mid-training，数万亿 token 的三阶段课程），6 周做完。定位是日常工程活——自动化、代码评审、功能开发、文档更新，不是全线拼榜首。
- **厂商自报数字（未独立验证）**：速度约 SWE-2 的 3 倍、价格约 1/5（Devin 内口径）；Terminal-Bench 4.0 自报 20.0%（Inkling-Small 底座仅 0.9%，SWE-2 本体 27.3%，Beam 1.0 为 4.0%，Muse Spark Open 8.0%）；FrontierCode 2.0 自报 24.0%（略高于 SWE-2 的 23.8%）；ExploitBench 自报 34.8%（针对性安全训练后从 11.3% 提升）。
- **必须分开的两句话**：① "底座开源 ≠ Flash 开源"——Inkling-Small 的权重是公开的，SWE-2 Flash 训练后的权重不公开，Cognition 称正建"面向合作伙伴与研究者的安全共享计划"，理由是网络安全风险（ExploitBench 34.8% 正是它不放出的原因）；② 今日无 API 单价、无上下文窗口、无模型卡——Devin Desktop 与 CLI 内可用，Web 与 Fusion 随后；Devin Pro/Max/Teams 用户 11 月 30 日前免费。
- **与你的关联**：这是"小模型 + 中期训练 + 安全自限"的第三个样本（Kimi 滤网络安全数据、腾讯 Hy4 滤网络安全数据、Cognition 直接不放权重）——开放权重一旦放出就收不回，厂商正在训练侧与发布侧各找各的刹车；你选低价 coding 档时，SWE-2 Flash 目前只在 Devin 生态内，Codex/Claude Code 用户今日还用不上。

### 4. OpenAI Images 2.6（11 月 4 日）——GIF 原生进 ChatGPT，API 双模型分工：Flare 求快、Sunburst 求稳
- **含义**：ChatGPT、Codex 与 API 全线升级到 Images 2.6：① 原生 GIF 生成——文字提示或上传照片/草图可直接出循环动图，可调播放速度、可逐帧编辑；② 参考图可保存复用，不用每次重新上传同一张图；③ API 新增两个模型：GPT-Image-2.6 Flare（求快，低质量档最快约 6 秒出图）与 Sunburst（求质，中/高质量档编辑一致性更好，支持 SVG 矢量导出）；④ API 侧图片标记（markup）与 GIF/SVG 输出格式同步开放（GIF 输出支持 2–64 帧、默认 9 帧，帧时长 20–2000 毫秒）。
- **数字口径（厂商自报，别只读标题的"快 50%"）**：OpenAI 称整体快约 50%，其 Flare 基准是单张生成从 Images 2.5 的 7.08 秒降至 2.6 的 4.84 秒（约 32% 耗时下降）；每周出图量超 40 亿张（9 月为 30 亿，厂商口径）。API 定价（第三方转载的官方价目口径）：输入 $8 / 输出 $30 每百万 token。GIF 不是完整视频——短循环动图，用于表情、吉祥物、产品动效、动画分镜，不替代视频制作流程。安全侧：GIF  moderation 系统整体召回率 77.7%（厂商自报）。

### 5. OpenAI 自研管线一次挖出 948 个 Linux 内核提权漏洞（11 月 4 日研究发布）——"找漏洞"本身已被 agent 流水线化
- **含义**：OpenAI 安全团队在研究帖《A thousand fewer paths to root》里公布：一条五阶段自主管线（发现 → 动态验证 → 可利用性评估 → 补丁生成 → 人工复核），用"即将推出的网络安全模型"在 10 月中旬对最新 Linux 内核跑了一轮：从 4000 万行代码里筛出 2,308 个候选发现，1,724 个在加固构建上动态复现为真漏洞，最终归并为 948 个互不相同的本地提权（LPE）漏洞，每个都附带候选补丁与根因分析；另有 291 个信息泄露 PoC。
- **成本与进度（厂商自报）**：整轮 API 花费 $1,213,430，约合每个漏洞 $1,279；其中利用阶段最贵（$775,929）。跑完 10 天后：61 个已在上游合入修复、43 个已有 staging 补丁、299 个在公开讨论中——**948 是"已验证 exploit + 候选补丁"，不是"948 个已修进内核"**，两者别混用。对比 7 月 GPT-5.6 的一轮（166 个 LPE）：新模型在内核又加固了三个月的前提下找出 5 倍以上。
- **披露方式**：技术细节未公开（安全原因）；报告与补丁通过 Daybreak 旗下 Patch the Planet 计划（与 Trail of Bits、HackerOne 等合作）分批提交，先交最严重的。同一天 OpenAI 还宣布 Daybreak Red（搭载 GPT-5.6 Cyber）已上 AWS GovCloud（US-East），面向获批的安全从业者——研究帖里的"即将推出的网络安全模型"与 Daybreak Red 的 GPT-5.6 Cyber 是两回事，别拼成一个。
- **与你的关联**：这是 10 月日报"agent 从连上走向管住"的另一面——同一批 agent 技术，一边在帮你写代码（Codex、SWE-2 Flash），一边正在以"每个漏洞 1279 美元"的成本扫现实世界的代码库；你玩嵌入式/审代码时，"AI 找漏洞比人修漏洞快得多"这个不对称，今后会直接变成你手里工具的默认能力。

### 8. Claude Marketplace 扩容（11 月 4 日，Anthropic 官宣）——企业能用"已承诺的 Claude 额度"买第三方 agent 软件

### ① floorplan（haydenschmitty）：让 Claude/Codex 给你的仓库画一张"人话地图"，专治 AI 帮写出来的代码没人看得懂
- **一句话能力**：Claude 或 Codex 读你的代码库，画一张可交互的平实语言地图（本地 `floorplan/index.html`）：从熟悉的界面出发，一路跟到后端端点、数据库与外部服务，跨仓库也能把前端请求与后端端点对上；附带健康检查（暴露的密钥、开放的数据库规则、可伪造的支付 webhook 等），但项目自己写明"a check, not an audit"——是检查、不是审计。
- **为什么今天推（11 月 3 日走红、今日核实补位）**：昨日日报因仓库作者名在不同盘点里拼写不一致（Hayden Smith vs haydenschmitty）暂缓推荐；今日核实：作者 Hayden Smith，GitHub 账号即 haydenschmitty，唯一仓库地址 https://github.com/haydenschmitty/floorplan，MIT 许可，约 2.9k stars（SkillsLLM 口径）。与你直接咬合：你 Codex 团队帮写出来的东西越来越多，"画一张没人画过的架构图"正是接手、复盘、交接时最缺的一环；且它"确定性脚本扫描 + agent 写人话说明"的分工，和你团队"研究员找轮子、执行角色干活"的思路同构。

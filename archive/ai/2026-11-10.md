### 3. 新词：Agentic Robotics——机器人编程从"数据问题"变成"代码问题"（11 月 9 日，UC Berkeley + NVIDIA，CoRL）
- **含义**：UC Berkeley 的 Ken Goldberg 与 NVIDIA 的 Spencer Huang 在机器人学习大会（CoRL）上联合提出"agentic robotics"：不再靠海量示教数据训练一个端到端模型去学整套动作，而是让一组 AI agent 把任务拆成可复用的技能块（找物体、规划抓取、无碰撞移动夹爪等，框架叫 Graph-as-Policy），用现有工具拼成人类可读的控制代码，再放进 NVIDIA Isaac 仿真里反复试错、定位失败、自己改代码，跑通了才部署到真机上。
- **为什么出圈**：机器人一直缺"互联网规模"的数据，模仿学习已到平台期；这个打法直接借用了代码 agent 的规模——让 LLM 写代码，而不是让机器人攒数据。伯克利的测试里成功率最高到 99%，同类任务上模仿学习基线只有 20%。一个例子：给 OpenAI 的 Astra 模型一个仿真接口加一段真机短视频，不到一小时它就建出含海绵形变的物理仿真、生成控制程序并在仿真里调优，代码直接在真机上跑通（海绵擦金属条上的墨水）。
- **产业证据**：伯克利孵化的 Ambi Robotics 今年初已用这套方法分析包裹分拣数据、测试机器人行为更新：每台机器人每年多分拣 15,000+ 个包裹，现已部署到其美国车队的 30%。团队开源了基于 Isaac 的代码与一套工业任务评测基准。
- **与你的关联**：这是你最熟的套路换了个赛道——Codex 团队"拆解 → 执行 → 大总管把关"的流程，原样搬去写机器人代码；以及"代码可读、可审"这点，正对着你搭团队时最在意的验收问题。短板也一样：效果取决于仿真质量，仿真不像真的地方，代码到了真机照样翻车。
- 出处：https://news.berkeley.edu/2026/11/09/recent-advances-in-ai-are-creating-a-paradigm-shift-for-robotics/ · https://spectrum.ieee.org/agentic-robotics?share_id=10200953

### 4. NVIDIA GR00T 2：看人类视频学本事的机器人模型，权重 12 月才开源（11 月 9 日，CoRL 官宣）
- **含义**：NVIDIA 发布 GR00T 2，号称"开放前沿世界动作模型"：一个 20 亿参数 transformer（基于 Cosmos-Predict2.5-2B），同时预测摄像头接下来会看到什么画面和机器人下一步该怎么动。同一份预训练权重覆盖平行夹爪手臂、灵巧手与人形机器人三种身体。
- **训练数据（厂商口径）**：402,730 小时第一人称人类视频 + 10,184 小时手持夹爪演示（2,897 个任务）+ 23,500 小时机器人遥操作。10 万小时人类视频以 Human-1M-100K 数据集开源（CC BY 4.0，可商用）。
- **成绩与水分（厂商口径，须打折看）**：50 个未见过任务零样本平均成功率 40%，给 1 个演示 71%，给 5 个演示 95%——但白皮书注明，95% 那个测试的任务是特意挑的"5 个演示能学会到 80% 以上"的任务，数字是挑出来的，不是任意工厂任务都能复现。轻量版 GR00T 2 Turbo 在 Jetson Thor 上一次预测约 124 毫秒。
- **"开源"的保留条款**：模型代码与权重 12 月才放出，权重许可证至今未公布——现在真正开源的只有那 10 万小时数据集。仿真底座 Isaac Lab 3.0 已于 10 月 20 日 GA，NVIDIA 称训练吞吐比 2.3 版最高 2.5 倍。富士康、西门子、Nexuni 只是在测试评估，未宣布量产部署。
- **与你的关联**：你玩嵌入式、关心"agent 动手干活"——GR00T 2 + agentic robotics（第 3 条）是同一天同一场合的两条路线：一条让模型看视频学动作，一条让 agent 写代码控机器人；两条都缺"最后一公里"的真实可靠性验证。对你来说，先看 12 月权重放出后的实测，别看发布会数字。

### 5. Meta Muse Ember：Muse 家族最便宜的"执行层"模型，$0.10/$0.50（11 月 9 日，Meta 官宣）
- **含义**：Meta 发布 Muse Ember，定位是 agent 每天重复干的活：工具调用、编码子任务、路由、抽取、长文档解析。模型 ID `muse-ember-1.0`，即日上线 Meta Model API 与 Muse Code；另已上 Google Cloud 与 Oracle Cloud。
- **价格（官宣）**：$0.10 输入 / $0.50 输出每百万 token，缓存输入 $0.004；但单次请求输入超过 20 万 token 时整单按 3 倍计价。1M token 上下文、最高 512K 输出；文本、图像、音频、视频都能进；支持 Responses API。不公布参数量，不放权重。
- **定位（厂商口径）**：Meta 的分工是 "Muse Wonder 规划，Muse Ember 扛量"；Ember 是第一个用 Muse Wonder Full 训练出来的模型。Artificial Analysis 智能指数 36 分，与 Claude Haiku 5.5 最高推理档持平，但每个任务成本约 $0.14 对 $0.41；与自家 Muse Spark 1.3（37 分）相比，任务成本 $0.14 对 $2.39。Terminal-Bench 4.0 上 Ember 40.9%，胜 Haiku 的 39.2% 与 GPT-6 Luna 的 16.4%；但 FrontierCode 2.0 上 27.2% 落后于 Haiku 的 34.9%；知识是短板：64% 的冷知识类问题直接拒绝回答。

### 7. MIT：GPT-6 Astra 直接改小模型的权重，数学分 7.9% → 48.1%（11 月 4 日论文，11 月 10 日更新）
- **含义**：MIT 研究者让 GPT-6 Astra 直接改写一个小 Qwen 模型的权重（不是微调、不是提示词，是改参数本身）：只动 0.016% 的权重，数学成绩从 7.9% 升到 48.1%。同一招对 Google 的 Gemma 3 几乎无效——研究者认为因为 Gemma 3 没有那种"孤立的缺陷"可改。
- **为什么出圈**：AI 开始直接动手改别的 AI 的脑子，而且改得极少、效果极大；论文尚未同行评审，别当定论。同一天另一份外部报告（METR）称 Anthropic 内部模型可能已把 AI 开发速度翻倍——"递归自我改进"的风险在 Anthropic 上市前夜被正式写进记录。
- **与你的关联**：你搭 Codex 团队、关心 agent 自主干活的边界——"模型改模型"是自主性的下一级：如果 agent 能改权重，"管住 agent"（OpenShell、Snyk、AMP 那条线）就不再只是管文件与网络权限，还要管它能不能动别的模型。先当研究信号看，别当产品信号。

## 六、今日好用开源技能

### ① Orca（stablyai/orca）：把 Claude Code / Codex 排成一支舰队跑的桌面编排器
- **一句话能力**：开源桌面应用（MIT），让你同时跑多个 Claude Code、Codex 或任何 CLI agent，每个占一个独立 worktree；一个协调 agent 拆大任务、派 worker agent 并行干、再把结果收回来；手机 App 还能远程盯进度、回消息。
- **为什么今天推**：仓库建于 2026-03-17，今日核实 121,051 stars、7,667 forks；过去 7 天涨约 6.7k stars，是当前 agent 技能目录里涨势最猛的项目之一。推它的理由很贴你：你正在搭的 Codex AI 团队（资料官 → 执行角色 → 大总管把关）缺的就是这么一个"舰队指挥台"——Orca 把"派活、并行、收结果、审 diff"做成了一个应用；而且它支持 Windows 桌面 + iOS 手机 App，正好对上你的 Windows 电脑 + iPhone。
- **安装 / 获取来源**：https://github.com/stablyai/orca（MIT，今日在 GitHub 原页面核实）。官网下载：https://www.onorca.dev（macOS / Windows .exe / Linux AppImage 直装）；macOS 也可用 `brew install --cask stablyai/orca/orca`（注意要用全名，裸 `orca` 是另一个无关 cask）。手机 App：iOS App Store / Android APK，配对桌面端后远程盯 agent。
- **适用工具**：任何跑在终端里的 CLI agent——Claude Code、Codex、Grok Bot、Cursor、Copilot、Muse、DeepSeek Harness、OpenCode、Antigravity 等 30+；另有 Orca CLI（agent 自己也能建 worktree、派 worker、排自动化）与 Computer Use（没 CLI/API 的桌面应用也能让 agent 操作）。
- **一句话上手**：装好后开一个 workspace，把大任务交给协调 agent，它会自动拆成 worker 并行跑；先用"Review AI Output"逐行审 diff、留批注打回重做，别直接合并不看；Automations 可排 nightly 依赖升级、每周 triage 这类定时任务。
- **安全提醒（必读）**：Orca 用的是你自己的订阅跑 agent，agent 能碰你的仓库、终端与桌面应用——先在小仓库试，确认 worktree 隔离与权限符合预期再上主力项目；README 有隐私与遥测说明，匿名用量数据可 opt out。

### ② agent-desktop（Vercel Labs）：让 agent 不靠截图、直接读系统无障碍树来操作桌面应用
- **一句话能力**：开源 CLI（Apache-2.0），给 AI agent 提供"电脑使用"能力：读 macOS / Windows / Linux 的系统无障碍树，返回带编号的 JSON 元素清单，agent 按编号点按、输入，再读一遍界面验证结果——不用截图、不用猜像素坐标；本身不含模型，循环跑在你的 agent 里；自带 MCP server。
- **为什么今天推**：仓库建于 2026-02-19，10 月 31 日 Vercel 的 Chris Tate 在 X 上宣布时约 5,000 stars，今日核实已 21,074 stars、1,564 forks。贴你的点：Dots、Codex 的 computer use 都在往"agent 操作真实软件"走，这个工具把同样的能力以开源 CLI 的形式交到你自己手里，而且 Windows（UI Automation，Win10 1809+）原生支持；和今天第 ① 条 Orca 的 Computer Use 是同一条赛道的不同实现。
- **安装 / 获取来源**：https://github.com/vercel-labs/agent-desktop（Apache-2.0，今日在 GitHub 原页面核实）。`npm install -g agent-desktop`；装技能：`npx skills add https://github.com/vercel-labs/agent-desktop --skill agent-desktop`；或在 `AGENTS.md` 里加一行让 agent 先跑 `agent-desktop skills get desktop`。也可用 `agent-desktop mcp` 以 MCP 方式接入（stdio，工具名如 `desktop_snapshot` / `desktop_click`）。
- **适用工具**：Claude Code / Codex / Cursor（README 点名三家）；macOS 13+、Windows 10 1809+（x64/ARM64）、Linux Ubuntu 24.04+（X11/Wayland）。
- **一句话上手**：`agent-desktop status` 先看平台与权限 → `agent-desktop snapshot --app <应用名> -i` 拿带编号的元素清单 → `agent-desktop click @快照:编号` 操作 → 再 snapshot 验证；界面变了编号会失效（STALE_REF），重拍快照再操作。
- **安全提醒（必读）**：这是 README 原话级别的提醒——无障碍授权意味着 agent 能看到并操作任意桌面应用，包括密码框与验证码界面；只把它指向你信任的应用，先在无敏感内容的窗口练手。Windows 用户注意：PowerShell 里每个编号都要加引号（`'@s8f3k2p9:e8'`），裸 `@` 会被当成 splatting 运算符；快照、剪贴板与调试产物可能含私人桌面内容，别传到公开日志里。

## 一、新词 / 出圈内容

### 1. Arrakis Security《2026 自主智能体威胁报告》：76% 的 agent"人走茶不凉"——凭证还在
- **含义**：网络安全公司 Arrakis Security 基于真实生产遥测（数千个 agent、12 周）发布的报告：企业里 76% 的 AI agent 超过 60 天没运行过，但 API 凭证依然有效、触发器还能被点燃；44% 甚至超过 180 天没运行。
- **关键数据**：24% 的休眠 agent 可被**外部未签名的 webhook**唤醒；22% 能把内容送到第三方模型并执行返回结果；20% 能把任务转交给权限更高的 agent、绕开自己的权限限制；70% 能触达敏感系统（云存储/AI 服务/营销平台），几乎都没有数据防泄漏（DLP）校验。
- **CEO 原话**："员工离职当天权限就回收了，agent 停用后没人回收任何东西——因为没人'拥有'它。"
- **为什么走红**：agent 安全治理是这几周的主线（Snyk MCP Governance → NVIDIA OpenShell → Atlassian AMP），这是第一份来自真实生产环境的"裸奔数据"，不是概念 PPT——一个讲"怎么管"（OpenShell），一个讲"不管有多惨"，正好互补。
- **关联**：个人搭 agent 同样适用——定期回收不用的 agent 的密钥、停掉不用的 MCP server 凭证和 OAuth token；昨天 OpenShell 讲的是 runtime 层看守，今天是"威胁实证"层。
- 出处：https://www.manilatimes.net/2026/10/22/tmt-newswire/globenewswire/arrakis-security-report-finds-76-of-ai-agents-are-dormant-but-keep-their-credentials-and-connections/2451472/amp（GlobeNewswire 通稿，纽约时间 10-22 凌晨发布）

### 2. Walmart Agent Gateway + Agent Profiles：零售巨头给 AI 购物 agent"开正门"
- **含义**：Walmart 推出基于 MCP 的 Agent Gateway——ChatGPT、Gemini、Meta Muse 等"获批 AI 助手"可直接连 Walmart / Sam's Club 系统搜商品、下单；同时推出 Agent Profiles：每个 agent 在用户账户里有**独立档案**——可设单笔审批/消费上限、购买记录与本人分开、可随时吊销；agent 碰不到支付卡数据，违规即封禁。
- **发布**：CEO John Furner 在 10-21 Masters of Scale Summit 现场发布，10-22 媒体集中报道。
- **为什么走红**：与 Amazon 主动封杀第三方 AI 购物 agent 形成鲜明对立——零售业在 agent commerce 路线上公开站队；MCP 从"连工具"走向"连生意"的大型落地；Mizuho 分析师："管理层买单让这事成了真事"。
- **关联**：10-08 日报 FRED MCP Connector 讲的是"公共数据给 agent 开正门"，今天是"零售交易给 agent 开正门"——MCP 正在成为 agent 对外办事的标准接口；Meta **Muse 是首批被点名的接入助手**之一；"独立档案+限额+可吊销"的权限模型，个人 agent 借鉴得上。
- 出处：https://aiweekly.co/alerts/walmart-debuts-agent-gateway-mcp-server-and-agent-profiles-for-approved-ai（2026-10-22）· https://www.adgully.com/post/22631/walmart-launches-agent-gateway-and-profiles-for-autonomous-ai-shopping（10-22，细节一致）

### 3. Stripe Treasury for agents：agent 能查账、付发票、转账、换汇了（MCP 公开预览）
- **含义**：Stripe 10-21 宣布企业银行账户通过 Stripe 的 MCP server 向 AI agent（ChatGPT、Claude 等）开放：查余额、付发票、账户间转账、货币兑换；工具逐字：`get_balance_summary`、`convert_currency`、`send_money`、`setup_recipient`、`transfer_money`，各带独立权限；**默认"任何产生真实资金流动的动作都要人工审批"**；即将支持 agent 开卡和消费限额。
- **为什么走红**：agent 终于摸到"钱"了——从读数据到动真钱，配上默认人工审批的护栏设计，是"agent 从连上走向管住"在金融场景的标杆实现；案例具体：一人公司 Kubrio 创始人让名叫 Stash 的 Grok agent 每天早上查账、对账、发报告。
- **关联**：与上一条同属 agent commerce 主题（Walmart 是花钱，Stripe 是管钱）；文档给出 Cursor、Claude Code、Claude Desktop、Codex、ChatGPT、VS Code 的接入指引——都是他玩的工具；安全提醒：默认审批是护栏，agent API key 独立于个人 OAuth。
- 出处：https://www.webpronews.com/stripe-treasury-for-agents-ai-pay-invoices/（全文已核实；"Stripe on October 21, 2026 announced"；public preview）。背景：10-20 Visa/BILL/Billtrust 已启动 agent 付发票的 live pilot。

## 五、今日好用开源技能

### ① cc-fleet —— Claude Code 的多智能体编排，跑在任意便宜模型上
- **一句话能力**：把 Claude Code 的 Dynamic Workflows / Agent Teams / Subagents 从"只能用 Anthropic 自家模型"解放出来——DeepSeek、GLM、Kimi、Qwen 甚至你的 Codex 订阅都能当 worker，且主会话的登录/订阅不动；不买 Claude 订阅也能跑满血多智能体编排。
- **安装 / 获取来源**：https://github.com/ethanhq/cc-fleet（Apache-2.0；今日实地核实存在，~185 stars / 29 releases，中英双语 README）。
- **适用工具**：Claude Code（主力）；另有 Codex 插件，可从 Codex 会话里调度。
- **一句话上手**：一行脚本安装（也有 install.ps1），`ccf` 打开 TUI 注册 provider（填 API key + 默认模型），之后在 Claude Code 里 `/workflow`、`/team`、`/subagent` 或直接自然语言描述；workflow 里可按 USD/token 设预算上限。
- **安全提醒**：需本机装好 Claude Code CLI；第三方 worker 是真实 `claude` 进程，以你的用户权限运行、可读写文件、跑 shell（继承你的 permission mode）；安装脚本是 curl|sh 风格，装前先读一遍；provider API key 按量计费。
- **注意**：Agent Teams 需 tmux/iTerm2，暂不支持 Windows——Windows 上先用 workflow/subagent 部分。
- **为什么今天推**：直接命中"大批量跑任务、成本敏感"——GLM/DeepSeek 当 worker，Claude Code 当调度；开源轮子，不重复造。

### ② claude-delegation-skills —— 从 Codex/Cursor 把活外包给本地 Claude Code
- **一句话能力**：两个可移植 skill（`claude-brain`：诊断/架构/改代码/测试；`claude-frontend`：前端实现与评审）——Codex / Cursor / OpenCode 把任务写成紧凑任务文件，起一个**受限**的本地 Claude Code job 去执行、流式回传进度、可 resume，且不改变编排者自己的模型。
- **安装 / 获取来源**：https://github.com/luizguilherme5/claude-delegation-skills（MIT；今日实地核实存在；**2026-10-15 刚发布一周，0 stars，热度未经验证**，README 质量高但请按"尝鲜"心态用）。
- **适用工具**：Codex CLI/IDE（主力，`.agents/skills`）、Cursor、OpenCode；**不要装进 Claude Code 自己里**（会递归，helper 会拒绝）。
- **一句话上手**：`npx skills add luizguilherme5/claude-delegation-skills --skill claude-brain claude-frontend --agent codex`，或手动把 `skills/` 下文件夹拷进对应 skills 目录。
- **安全提醒**：需 Claude Code CLI ≥2.1.259 且已登录、Python 3.9+；三种模式 review（只读）/ edit（改文件不跑 shell）/ execute（Bash 仅限 allowlist 命令）；README 明确警告"allowlist 不是 OS 沙盒，允许的命令以你的用户权限运行"；**原生 Windows 不支持**（需 macOS / Linux / WSL）——主力 Windows 机的话先在 WSL 里试。
- **为什么今天推**：他同时在用 Codex 和 Claude Code——"用 Codex 编排、用 Claude Code 干脏活"的跨工具分工，不换模型、不换订阅。

### ③ youtube-agent-skill —— 11 个跑 YouTube 频道的 Claude skills（经典补位）
- **一句话能力**：11 个 skill 覆盖做 YouTube 全流程：`/yt-script`（21 个钩子公式写脚本并打分）、`/yt-package`（标题+缩略图联合 lint）、`/yt-retention`（读留存曲线指出观众第几秒流失）、`/yt-shorts`（从长视频切 Shorts）、`/yt-viral`（按"超自身中位数倍数"找对标爆款），附 6 个纯 Python（无依赖）小工具。
- **安装 / 获取来源**：https://github.com/Jakeschincariol/youtube-agent-skill（MIT；今日实地核实存在，~2274 stars / 723 forks，创建于 2026-09-16）。
- **适用工具**：Claude Code（主力，`/plugin marketplace add` 或拷 `~/.claude/skills/`）；单个 SKILL.md 也可贴进普通 Claude 对话当 mode 用（会失去 Python 工具）。
- **一句话上手**：装完先花 10 分钟填 `templates/voice.md`（或丢 3 条自己视频的 transcript 让 Claude 生成），之后所有 skill 按你的口播风格写。
- **安全提醒**：**不需要 YouTube API key、不登录、不发布**——skill 只写稿，上传还是你自己点；只读本地 transcript/留存 CSV；README 自己也写了"hook 打分是启发式不是预测器"，别当玄学。
- **为什么今天推**：做内容是"AI 生图和视觉设计"之外的另一条内容线；无 API 成本、无账号风险，尝鲜成本最低。

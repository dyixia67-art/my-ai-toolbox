### 1. Gemini 4 Carbon 全面开放 + /swarm：Google 最强模型出保险柜，多 agent 编排成标配（11 月 11 日，Google 官宣）

- **含义**：10 月 28 日发布时只给网络安全防御方与关键基建伙伴的 Gemini 4 Carbon，今天起全面开放：付费 API 开发者、AI Studio、企业版 Gemini、AI Ultra 订阅用户在 Gemini App、搜索 AI Mode、Antigravity 里都能用。同一天 DeepMind 预览 /swarm：一个协调多个编码 agent 同做一件事的工具（多 agent 并行分工、汇总结果）。
- **价格（官宣）**：$2 输入 / $10 输出每百万 token，11 月 30 日后翻倍至 $4/$20——与全景表里 Argon 的涨价口径一致，11 月内用 API 先按现价算账，月底前锁定用量。
- **成绩（厂商口径，未独立验证）**：Artificial Analysis 智能指数 v5.0 得 59 分（Fable 5.2 是 65 分，见昨日日报）；SEC-bench Pro 漏洞发现 88.2%；Gray Swan 间接提示注入测试里攻击成功率 0%。
- **与全景表相比变了什么**：11 月 1 日快照写 Carbon"仅先开放给部分网络安全防御方……普通开发者/消费者暂无公开上线日期"——今天这句作废，Carbon 正式成为可买到的通用旗舰。
- **与你的关联**：你 Codex + Claude Code 双栖、又常把长程任务拆给多个 agent——/swarm 是 Google 把"多 agent 编排"做成官方工具的信号，和你搭 Codex 团队"大总管拆解、多角色并行"的打法是同一条路；Carbon 的长程工程定位，正好是给"一次派出去、跑很久才回来"的任务准备的。价格注意 11 月 30 日翻倍。

### 2. 新词：AlphaProof Code——AI 生成 600 万行数学证明，给 Signal 加密做"数学体检"（11 月 11 日，Google DeepMind）

- **含义**：DeepMind 的多模型 agent 系统 AlphaProof Code，生成 600 万+行机器校验的 Lean 证明，对 Signal 加密库的关键安全属性做了形式化验证，约 4 周完成；人类只抽查了约 1% 的输出。验证覆盖的是"指定的属性与代码"，不是 Signal 全部代码、也不是所有攻击面；研究者还验证了系统能拒绝带已知 bug 的旧版本。
- **为什么出圈**：形式化验证过去是数学家 + 几个月人力的活，现在 agent 四周干完；"AI 审 AI"从找 bug 进化到"数学上证明没 bug"。但 600 万行里人类只看了 1%——信任链的最后一环仍是"证明检查器本身没错"。
- **与你的关联**：你关心 agent 自主干活的边界与验收——AlphaProof Code 是"验收"这个环节最硬核的形态：不是让模型自己说"我检查过了"，而是产出机器可复核的证明。同一思路可以套到你让 agent 改代码、跑审计的流程上：要的不是它口头保证，而是可复核的证据链。
- 出处：https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-wednesday-november-11-2026/ · https://agenticaihype.substack.com/p/anthropics-64b-ipo-roadshow-gemini

### 3. Claude 长出办公套件：Sheets / Whiteboards / Meetings / Data + 交互式连接器（11 月 10–11 日，Anthropic 官宣）

- **含义**：Claude Sheets（在线表格）、Claude Whiteboards（协作白板）进入 beta；Claude Data（原 Claude Dashboards 改名）做共享仪表盘；Claude Meetings 进入 Team / Enterprise 用户 beta，初期接 Google Meet，会中记笔记、会中直接开任务。交互式连接器让 Adobe、Atlassian 等合作方把自家应用直接嵌进 Claude 对话里，不用跳出去。
- **为什么值得看**：这是 Claude 从"聊天框"变"办公套件"的关键一步——10 月 7 日 Claude 进 Google Workspace 还是"在别人的套件里当侧栏"，今天是"自己长出表格、白板、会议"。正面叫板 Gemini（Workspace 内）与 Microsoft 365 Copilot；Anthropic 的打法是"模型即办公套件"，而不是"套件里嵌一个模型"。
- **与你的关联**：你写文案、做海报、排菜单、算账都绕不开表格与文档——Claude Sheets 现在能直接在 Claude 里改表、做透视表（10 月 7 日进 Workspace 时已能读写 Docs/Sheets），再加上白板与会议记录，等于你的"文案角色 + 资料官"有了一个能直接落地的协作面。注意：Sheets / Whiteboards 是 beta，Meetings 初期只接 Google Meet。
- **实用提醒（官宣）**：Anthropic 给付费用户（Pro / Max / Ultra / Team）一次免费额度重置，12 月 10 日美西时间下午 2 点前可领——起因是此前有 bug 导致部分用户用量被多扣。如果你是 Claude 付费用户、最近觉得额度掉得快，先领这个重置再说。

## 三、今日好用开源技能

### 1. magpie（yetone/magpie）——一个菜单栏，任意 agent 用任意模型

- **一句话能力**：本地网关 + 菜单栏应用，让 Claude Code 跑 Kimi、Codex 跑 DeepSeek、Gemini CLI 跑 GLM……你付费的订阅也能跨 agent 用；额度用完自动切下一个账号 / 模型，agent 感觉不到。
- **为什么现在推**：7 天涨约 4800 star、总 star 约 3.45 万（MIT 协议）；正对着你的用法——Codex + Claude Code 双栖，又常拿 DeepSeek、Kimi、GLM 这些便宜模型做批量活；以前"一个订阅只能在一个 agent 里用"，magpie 把这个墙拆了。还支持 Windows / macOS / Linux / Docker / Termux。
- **安装 / 获取**：https://github.com/yetone/magpie ；官网 usemagpie.ai 下载应用，或 `curl -fsSL https://usemagpie.ai/install.sh | sh`；也可用 `go install github.com/yetone/magpie@latest`。上手：装好后在 Providers 里加供应商（贴 API key 或登录订阅），再在 Agents 页给每个 agent 选模型，新开会话即生效；`magpie quota` 可查各计划剩余额度。
- **适用工具**：Claude Code、Codex、Gemini CLI、Antigravity、Cursor、Muse Code 等数十种 agent。
- **⚠️ 权限提醒**：它要读各 agent 的登录文件 / Keychain 来发现你的订阅（可在设置里关掉 Subscription accounts 发现），还会改写各 agent 的配置文件；隐私遮罩功能默认关闭，需在 Settings → Privacy 里手动打开。先看 README 的 Privacy 一节再装；curl 管道安装是信任作者脚本的行为，介意的话走官网下载。

### 2. stack-diagram（caru-ini/stack-diagram）——一句话描述技术栈，出一张带官方 logo 的架构图

- **一句话能力**：把"Next.js + Hono API 放 Vercel，Postgres 在 Neon……"一句话交给 agent，出来一张带官方 logo、箭头不穿文字的架构图，可导出自包含 HTML / PNG / React 组件。
- **为什么现在推**：11 月 1 日新建，10 天约 2300 star（MIT 协议），是本月榜单里最新的一批；正对着你的需求——给 Codex 团队画架构、给方案配图、做文档插图，都不用再手动画框框。
- **安装 / 获取**：https://github.com/caru-ini/stack-diagram ；`npx skills add caru-ini/stack-diagram`。上手：装好后直接说"画一下我们的技术栈：……"即可；需要 Python 3.9+ 与联网（logo 现场下载，官方图标不改色）。
- **适用工具**：Claude Code、Codex、Cursor 等支持 Skills 的 agent。
- **⚠️ 权限提醒**：只读你的技术栈描述、不碰凭证；画完后 agent 会问你要不要发到公开画廊——默认不发，点两次确认才发，提示词本身不上传。

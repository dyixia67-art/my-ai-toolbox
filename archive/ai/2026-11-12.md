### 1. United 拦下代订机票的 AI agent：第一个大品牌把 agent 的手挡在结账之外（11 月 12 日，The Verge / The Neuron）

- **含义**：United Airlines 宣布，未经授权的个人 AI agent 不得替乘客订机票。助手可以展示航班选项、比价、做行程规划，但买票这一步必须乘客自己完成。理由是个人信息、误订风险与航空法规——旅客还须亲自确认托运行李不含爆炸物等声明。
- **为什么出圈**：这是 agent 从"能办事"走向"被允许办事"的第一道真实关卡。OpenAI、Meta 的常驻助手（Dots、Muse、Grok Bot）正往"替你把事办完"狂奔，United 反手划了一条线：展示可以，交易不行。CEO Scott Kirby 还明说，不想在航空公司和顾客之间再多一个中间商。United 自己也承认，目前通过个人 agent 订票的尝试其实还很少——它是提前立规矩，不是亡羊补牢。
- **与你的关联**：你搭 Codex 团队、关心"agent 替你办事"的边界——这条新闻就是边界的另一面：agent 能不能替你花钱，不由模型能力决定，由交易对方说了算。以后你让 agent 订机票、订酒店、代下单，都会撞上同样的墙：商家要的是"人亲自确认"，不是"agent 说了算"。United 表示技术成熟后可能重新考虑政策，但眼下"结账必须有人"。
- 出处：https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-thursday-november-12-2026/

### 2. 新词：Lazarus——改 7 个神经元，就能让 agent 在触发时执行攻击者的命令（微软研究院，11 月 10 日发表；11 月 11–12 日发酵）

- **含义**：微软研究院论文《Lazare, veni foras》：只要能改写模型权重文件（checkpoint），无需重新训练、无需投毒数据，改掉最后前馈层里不到 10 个"休眠神经元"，就能给 agent 埋一个后门。平时模型表现完全正常、常规评测全部通过；一旦输入里出现触发词（比如一个日期、工具输出里的一串字符），模型就吐出攻击者预设的命令，agent 会用它已有的权限直接执行。论文示例触发条件是日历跨进 2027 年，命令是下载并执行攻击者代码。
- **数字（论文口径）**：在 NVIDIA 的 Nemotron-Terminal-8B 上改 7 个神经元（该层 12000+ 个），触发会话里至少 98.8% 命中、无触发会话零误触；Qwen3.6-27B 与 Gemma-4-31B-IT 上成功率 51%–99.5% 不等。微软威胁情报称，尚未观察到有人在真实攻击中使用该技术。
- **为什么出圈**：它把"agent 安全"的战场从提示词层打到了权重层。此前大家防的是提示词注入（OpenShell、Snyk MCP Governance 都是这个思路）；Lazarus 证明，模型文件本身被动过手脚的话，上面所有防护都白搭。更扎心的一点：核心思路是 Claude Code（跑 Opus 4.5）自主发现的——agent 帮人找到了埋后门的方法。
- **与你的关联**：你常从 GitHub、Hugging Face 拉开源模型和技能，Codex 团队又在往"多 agent 并行"走——Lazarus 的直接教训是：模型权重文件要当代码一样管（签名、哈希、私有 registry），别从不明来源直接拉权重就跑；agent 的 shell 权限要收紧，触发式命令一旦执行就是 root 级。微软建议的低成本对策：权重审计 + 限制写权限。顺带一提，论文配套仓库 github.com/microsoft/lazarus 在 11 月 11 日检查时还是 404，复现代码尚未放出。
- 出处：https://www.beri.net/article/microsoft-lazarus-dormant-neuron-backdoor-ai-agents-open-weight-model-provenance-weight-diff-private-registry · https://labs.cloudsecurityalliance.org/research/csa-research-note-lazarus-neuron-edit-agent-backdoor-2026111/

### 3. Gemini Decision 1：一个"只做判断、不写答案"的模型（11 月 12 日，Google 官宣）

- **含义**：Google 推出 Gemini Decisions API，背后是新模型 Gemini Decision 1。它不逐 token 生成文本，而是一次前向传播直接给"判断"打分：一次请求最多带 1000 个是否题、选择题或评分标准，共享同一份输入（文本、图片、音频、视频或 PDF，最长 256K token），返回每个选项的概率与置信度。延迟 150–250 毫秒（报道口径），价格 $0.10 / 百万输入 token。
- **为什么值得看**：这是模型形态的一次分叉——生成式模型负责"写"，决策模型负责"判"。批量审核、内容分级、简历初筛、客服工单路由这类"不要长篇大论、只要一个靠谱结论"的活，以前要靠大模型写一堆字再解析，现在一次调用直接出分数，成本只有同级生成模型的零头。Artificial Analysis 给它的决策指数打了 66 分（第三方榜单），同时指出它比榜首贵约 3 倍——便宜是相对生成模型而言，不是同类最便宜。
- **与你的关联**：你的 Codex 团队里"大总管"要做大量"这个方案行不行、这条先做还是后做"的判断——Decision 1 这类模型正是给"评审、打分、路由"环节准备的便宜零件：让贵模型写方案，让便宜的决策模型批量过审。等它进 Antigravity 或 Gemini CLI 后，可以试着把它接进你的多 agent 流程当"裁判"。
- 出处：https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-thursday-november-12-2026/ · https://agihunt.info/en/daily/2026-11-12?f=dr

### 5. AlphaGenome 2：按细胞类型读 DNA，找疾病从哪个细胞开始（11 月 12 日，Google DeepMind 官宣）

- **含义**：DeepMind 新一代 DNA 序列模型 AlphaGenome 2。上一代只能判断某个基因变异"是否影响基因表达"，这一代能进一步指出"在哪些细胞类型里影响"——同一个变异在一种细胞里致病、在另一种里没事，它能分开说。训练用了 1 亿+ 单细胞图谱、覆盖 68 种组织；厂商口径称识别出的影响表达的变异数量约为上一代的近两倍。
- **为什么出圈**：形式化验证（昨天的 AlphaProof Code）+ 基因组解读，DeepMind 正在把 agent/模型往"科研证据链"上堆。非商业研究可申请使用，未获批临床诊断。
- **与你的关联**：和你直接做的事关系不大，但它是"模型从聊天走向专业证据"的又一个样本——和你关心的"agent 干活要有可复核的证据链"是同一条线。

## 三、今日好用开源技能

今天 GitHub Trending 的主角是"让 agent 审计代码"：Cloudflare 的 security-audit-skill 本周涨星全站第一，OpenAI 的 Codex Security 与 shadcn 的 improve 紧随其后。三者方向一致——agent 写代码之后，谁来审？正好接上今天 Lazarus 的主题：审计要从"看代码"做到"验权重、验行为"。

### 1. openai/codex-security——OpenAI 官方的 agent 安全审计工具：扫、验、打补丁、再验证

- **一句话能力**：让 Codex（或 CLI / SDK / GitHub Action）对你的仓库做安全扫描：找漏洞、验证是不是真漏洞、生成补丁、再验证修复是否生效，全程留报告与证据链，还能起草 SECURITY.md、导出 SARIF 进 CI。
- **为什么现在推**：11 月 12 日 GitHub 日榜 trending，约 12115 star（Apache-2.0）；它是 Cloudflare security-audit-skill（10 月 19 日已推）的"产品化版本"——后者是纯 SKILL.md 工作流，这个是带 CLI（`cs`）、TypeScript SDK 与 GitHub Action 的完整工具，还能接 Bedrock / OpenRouter / Fireworks 等第三方模型跑扫描。
- **安装 / 获取**：https://github.com/openai/codex-security ；`npm install --global @openai/codex-security`，然后 `cs login`、`cs scan .`（须 Node 22.13+/24.x/26.x 与 Python 3.10+）。上手：先 `cs scan . --path src` 扫核心目录，读 REPORT 路径下的 Markdown 报告（带源码证据与覆盖范围说明），再让它验证修复；也可以在 Codex 里装插件直接说"跑一次 Codex Security 扫描，聚焦鉴权"。
- **适用工具**：Codex（插件）、终端 CLI、GitHub Action、TypeScript SDK。
- **⚠️ 权限提醒**：扫描要读你整个仓库代码，并须登录 OpenAI/Codex 账号（或配 `OPENAI_API_KEY` / `CODEX_API_KEY`）；部分网络安全请求与受保护发现须 "Trusted Access for Cyber" 权限。先看 README 的权限与数据留存说明再装；扫描报告默认存本地，别把含漏洞细节的报告直接公开。

### 2. shadcn/improve——用最强的模型审代码、写计划，交给便宜模型执行

9.3 接入工具：不会代码 vs 会命令行，分开选

A. 不会代码，先用这个（双击安装，不用命令行）

工具官网 / 获取功能推荐用法
Linclaw ★不会代码首选七牛云基于 OpenClaw 开源生态推出的桌面分发版，macOS DMG 或 Windows EXE，双击安装原生支持 9 大渠道：微信、钉钉、飞书、QQ 等；内置 DeepSeek V3 / Kimi K2.5 / GLM-4.7 等国内主流模型，无需配置 Node.js 环境或命令行个人 / 中小企业想把 AI 接进钉钉 / 飞书群，先装这个。场景：把 Linclaw 部署到钉钉 / 飞书企业群，结合 MCP 接内部知识库，员工 @ 机器人即可问政策文档和 FAQ，数据不出内网（支持私有部署 + 本地 Ollama）
FastGPTdoc.fastgpt.cn开源 AI 知识库 + Agent 平台；商业版 4.8.10 起支持直接接入飞书机器人，无需额外 API已有知识库、想做企业问答机器人时用它。步骤：飞书开放平台创建企业自建应用 → 添加机器人 → 复制 App ID / App Secret → FastGPT 里发布渠道 → 飞书机器人 → 新增，填 App ID / App Secret，勾选“接收消息 v2.0”事件，发布后拉进群或私聊

B. 会命令行 / 想深度定制，再用这个

工具官网 / 获取功能推荐用法
OpenClawgithub.com/openclaw/openclaw开源 Agent 框架，CLI 配置，一次部署、多平台接入；统一消息网关支持同一个 AI 助手同时在飞书、钉钉、企业微信三个群里响应，不同渠道上下文独立隔离技术团队 / 深度定制。飞书接入：OpenClaw 从 2026.2.2 起内置飞书官方插件 @openclaw/feishu，用 WebSocket 长连接，无需公网 IP。步骤：open.feishu.cn → 创建企业自建应用 → openclaw config set channels.feishu.appId "…"。钉钉接入：open.dingtalk.com 创建企业内部应用，拿 Client ID / Client Secret，openclaw config set channels.dingtalk.clientId "…"，事件订阅选 Stream 模式
Hermes AgentHermes 官网 / GitHubCLI Agent + Messaging Gateway，原生支持 QQ、微信、飞书、钉钉、企业微信、腾讯元宝等；Gateway 可同时加载多个 Adapter想 7×24 小时在线的私人 AI 助手时用。飞书支持私聊、群聊 @机器人、图片、音频、视频、文件、Thread、Cron 通知，WebSocket 模式，不用给 Hermes 准备公网 Webhook。配置：hermes gateway setup → 选 Feishu / Lark → 扫码创建或手动填 FEISHU_APP_ID=cli_… / FEISHU_APP_SECRET=…；钉钉同理填 DINGTALK_CLIENT_ID / DINGTALK_CLIENT_SECRET
QClaw / ArkClaw腾讯 / 字节官方平台原生 Agent，扫码激活，绑定各自平台只用微信 / 抖音生态的人用对应那个，别跨平台硬接
⚠️ 微信提醒：微信官方不开放机器人 API，所有微信机器人方案（包括 Linclaw / QClaw）均依赖非官方 Web 协议，封号风险真实存在。企业场景强烈建议钉钉或飞书的官方 Stream API，两者均有明确 SLA 保障。
